Caminho principal

1. Função do 1º grau: o que o a e o b fazem

Função do 1º grau é f(x) = ax + b, com a ≠ 0. O gráfico é sempre uma reta. O b é onde a reta corta o eixo y (a altura no x = 0). O a é a inclinação: quanto a reta sobe a cada 1 passo pra direita (se a for negativo, ela desce).

f(x) = 2x − 3
Aqui a = 2 e b = −3.
f(0) = 2 · 0 − 3 = −3
No x = 0, o termo com x vira zero. Sobra só o b: a reta corta o eixo y em (0, −3).
f(1) = −1   f(2) = 1   f(3) = 3
Cada passo de 1 pra direita, a altura sobe 2 (de −1 pra 1, de 1 pra 3). Esse 2 é o a.
Marco os pontos e passo a régua. Na verdade dois pontos já bastam pra desenhar uma reta.
Tracejado: 2x − 3. Verde: −2x − 3. Com a negativo, a reta desce: cada passo pra direita, a altura cai 2. O b é o mesmo, então as duas cortam o eixo y no mesmo lugar.
Robozinho perguntaEm f(x) = 5x + 1, onde a reta corta o eixo y?

Em (0, 1): f(0) = 5 · 0 + 1 = 1. É sempre o b.

Robozinho perguntaA reta f(x) = −x + 4 sobe ou desce?

Desce: a = −1 é negativo. Cada passo pra direita, a altura cai 1.

Robozinho perguntaOnde f(x) = 4x − 8 corta o eixo x?

Onde a altura é zero: 4x − 8 = 0, então 4x = 8 e x = 2. O ponto é (2, 0). Esse x se chama raiz (ou zero) da função.

Saiba mais: e quando a = 0?

Fica f(x) = b, uma função constante: reta deitada, sempre na mesma altura. Não se chama "do 1º grau" porque o x sumiu, mas aparece bastante. Já uma reta em pé (tipo x = 3) nem é função: um único x com infinitas saídas.

2. Achar a reta que passa por dois pontos

Dois pontos decidem uma reta. O a é a diferença das alturas dividida pela diferença dos x: y2 − y1x2 − x1. Depois, pra achar o b, coloca um dos pontos na fórmula.

(1, 1)  e  (3, 5)
Quero a reta que passa por esses dois pontos.
a = 5 − 13 − 1 = 42 = 2
Quanto subiu (de 1 pra 5: subiu 4) dividido por quanto andou pro lado (de 1 pra 3: andou 2). Subiu 2 por passo.
1 = 2 · 1 + b  →  b = 1 − 2 = −1
O ponto (1, 1) diz: quando x = 1, a altura é 1. Coloco isso em y = 2x + b e sobra só o b pra descobrir.
f(x) = 2x − 1   confere: 2 · 3 − 1 = 5 ✔
Sempre confere no outro ponto. Se não der, alguma conta escorregou.
No desenho: o "degrau" laranja mostra andar 2 e subir 4.
Robozinho perguntaA reta passa por (0, 4) e (2, 0). Qual o a?

(0 − 4) ÷ (2 − 0) = −4 ÷ 2 = −2. Desce 2 por passo.

Robozinho perguntaE o b dessa reta?

O ponto (0, 4) já está em cima do eixo y, então b = 4. A reta é f(x) = −2x + 4.

Robozinho perguntaSe eu trocar a ordem dos pontos na conta do a, muda alguma coisa?

Não: (4 − 0) ÷ (0 − 2) = 4 ÷ (−2) = −2 também. Só não pode misturar: o primeiro y de cima tem que ser do mesmo ponto que o primeiro x de baixo.

Saiba mais: essa conta volta em Cálculo 1

Numa reta a inclinação é a mesma em qualquer pedaço (é isso que faz ela ser reta). A conta "quanto subiu ÷ quanto andou" é a taxa de variação média. A derivada, em Cálculo 1, é essa mesma conta com os dois pontos chegando cada vez mais perto um do outro.

3. Equações e inequações do 1º grau

Equação é uma balança: o que fizer de um lado, faz do outro, até sobrar o x sozinho. Inequação (com <, >, ≤, ≥) é igual, com uma pegadinha: multiplicar ou dividir por número negativo vira o sinal.

5x − 4 = 2x + 8
Quero o x que deixa os dois lados iguais.
5x − 2x = 8 + 4
Tiro 2x dos dois lados e somo 4 nos dois lados. (É o atalho "passa pro outro lado trocando o sinal".)
3x = 12  →  x = 123 = 4
Divido os dois lados por 3.
5 · 4 − 4 = 16    2 · 4 + 8 = 16  ✔
Conferindo: os dois lados dão 16.
−3x + 2 > 8  →  −3x > 6
Agora uma inequação. Tiro 2 dos dois lados (isso não mexe no sinal).
x < 6−3 = −2
Divido por −3. Como é negativo, o > vira <. Teste com x = −3: −3 · (−3) + 2 = 11, e 11 > 8 ✔.
Robozinho perguntaPor que o sinal vira quando multiplica por negativo?

Exemplo: 2 < 5. Multiplicando os dois por −1: −2 e −5. Só que −2 é maior que −5 (fica mais perto do zero, na direita). A ordem inverteu.

Robozinho perguntaResolva 2x + 1 = 2x + 7.

Tirando 2x dos dois lados: 1 = 7. Isso é falso para qualquer x. Então a equação não tem solução.

Robozinho perguntaE 3(x + 1) = 3x + 3?

Fazendo a distributiva: 3x + 3 = 3x + 3. Tirando 3x: 3 = 3, sempre verdade. Então todo x real é solução.

Saiba mais: equação com fração

Multiplica tudo pelo denominador (ou pelo MMC) logo no começo. Cuidado: se um lado tem soma, o número multiplica o lado inteiro, então vai entre parênteses. Depois que a fração sumiu, a conta é igual às de cima.

4. Função do 2º grau: a parábola

Função do 2º grau é f(x) = ax² + bx + c, com a ≠ 0. O gráfico é uma parábola. Com a > 0, a boca é pra cima; com a < 0, pra baixo. O c é onde ela corta o eixo y.

f(x) = x² − 4x + 3
Aqui a = 1, b = −4 e c = 3. Repara que o a = 1 não aparece escrito: x² é o mesmo que 1 · x².
x: 0, 1, 2, 3, 4  →  f(x): 3, 0, −1, 0, 3
Tabelinha. Exemplo: f(2) = 2² − 4 · 2 + 3 = 4 − 8 + 3 = −1.
Ligando os pontos sai uma parábola de boca pra cima. Os valores se repetem dos dois lados do x = 2 (3, 0, −1, 0, 3): ela é simétrica.
f(0) = 0 − 0 + 3 = 3 = c
No x = 0, os termos com x somem e sobra o c. Ela corta o eixo y em (0, 3).
Com a negativo a boca vira pra baixo. Este é −x² + 2x + 3.
Robozinho perguntaA parábola de f(x) = −3x² + x + 7 tem boca pra cima ou pra baixo? Corta o eixo y onde?

Pra baixo, porque a = −3 é negativo. Corta o eixo y em (0, 7), porque c = 7.

Robozinho perguntaPor que precisa ter a ≠ 0?

Com a = 0 o x² some e sobra bx + c, que é uma reta (1º grau).

Saiba mais: o que o tamanho do a faz

Quanto maior o a (sem olhar o sinal), mais fechada a parábola: 3x² sobe bem mais rápido que x². É o "esticar" de Gráficos e transformações.

5. Raízes: o Δ e a fórmula de Bhaskara

Raízes são os x em que f(x) = 0: onde a parábola corta o eixo x. A fórmula: Δ = b² − 4ac e x = −b ± √Δ2a. Se Δ > 0, são duas raízes; se Δ = 0, uma só; se Δ < 0, nenhuma raiz real.

x² − 4x + 3 = 0
Quero os x em que a altura é zero. a = 1, b = −4, c = 3.
Δ = (−4)² − 4 · 1 · 3 = 16 − 12 = 4
Primeiro o Δ (delta). Cuidado: (−4)² = (−4) · (−4) = +16. Por isso o parênteses.
x = −(−4) ± √42 · 1 = 4 ± 22
−b = −(−4) = 4. A raiz de 4 é 2. Embaixo, 2a = 2 · 1 = 2.
x = 4 + 22 = 3   ou   x = 4 − 22 = 1
O ± quer dizer duas contas: uma com mais, outra com menos.
x² − 2x + 5:   Δ = 4 − 20 = −16
Outro exemplo. Δ negativo: raiz de número negativo não existe nos reais. Essa parábola não encosta no eixo x.
Os três casos. Verde: Δ > 0, corta o eixo em 2 pontos. Laranja (x² − 6x + 9): Δ = 0, só encosta em 1 ponto. Azul (x² − 2x + 5): Δ < 0, não toca.
Robozinho perguntaEm x² − 6x + 9 = 0, quanto vale o Δ? Quantas raízes?

Δ = (−6)² − 4 · 1 · 9 = 36 − 36 = 0. Uma raiz só: x = 6 ÷ 2 = 3. A parábola encosta no eixo em (3, 0).

Robozinho perguntaEm x² − 9 = 0 (sem o termo com x), precisa de Bhaskara?

Não: x² = 9, então x = 3 ou x = −3. Não esquece do negativo: (−3)² também dá 9.

Robozinho perguntaE em x² − 5x = 0 (sem o número solto)?

Coloca o x em evidência: x(x − 5) = 0. Uma multiplicação só dá zero se um dos dois for zero: x = 0 ou x = 5. Não divide por x, senão o x = 0 some.

Saiba mais: soma e produto, e a fatoração

Quando a = 1, as duas raízes somam −b e multiplicam c. Em x² − 4x + 3: que dois números somam 4 e multiplicam 3? O 1 e o 3. Dá pra achar de cabeça quando os números são pequenos, e serve pra conferir a fórmula.

E com as raízes x₁ e x₂ dá pra fatorar: ax² + bx + c = a(x − x₁)(x − x₂). Exemplo: x² − 4x + 3 = (x − 1)(x − 3). Isso liga com Fatoração.

6. O vértice, e onde a parábola sobe e desce

O vértice é a ponta da parábola: o ponto mais baixo (se a > 0) ou o mais alto (se a < 0). O x do vértice é −b2a e fica bem no meio das raízes. O y do vértice é só calcular a função nesse x. De um lado do vértice a parábola desce, do outro ela sobe.

x² − 4x + 3:   xv = −(−4)2 · 1 = 42 = 2
Fórmula do x do vértice, com a = 1 e b = −4.
meio das raízes: 1 + 32 = 2 ✔
As raízes eram 1 e 3. A parábola é simétrica, então a ponta fica bem no meio.
yv = f(2) = 4 − 8 + 3 = −1
Pro y do vértice, coloco o x do vértice na função.
Vértice (2, −1). A linha tracejada em pé é o eixo de simetria: um lado é o espelho do outro.
desce em ]−∞, 2]  ·  sobe em [2, ∞[
Boca pra cima: vindo da esquerda, ela desce até o vértice e depois sobe. A imagem (as alturas que ela atinge) é [−1, ∞[.
Robozinho perguntaQual o vértice de −x² + 2x + 3?

x do vértice = −2 ÷ (2 · (−1)) = −2 ÷ (−2) = 1. y do vértice = −1 + 2 + 3 = 4. Vértice (1, 4), o ponto mais alto (boca pra baixo).

Robozinho perguntaOnde −x² + 2x + 3 é crescente?

Boca pra baixo: sobe até o vértice, depois desce. Crescente pra x ≤ 1 e decrescente pra x ≥ 1.

Saiba mais: de onde vem o −b/2a

As raízes são −b + √Δ2a e −b − √Δ2a. Fazendo a média das duas, o +√Δ e o −√Δ se cancelam e sobra −b/2a. Funciona até quando Δ < 0: a simetria continua lá, só não tem raiz.

Outro jeito: x² − 4x + 3 = (x − 2)² − 1. É o x² andando 2 pra direita e 1 pra baixo (Gráficos). Por isso a ponta foi pra (2, −1).

7. Esboçar a parábola sem tabela

Quatro informações bastam: (1) a boca, pelo sinal de a; (2) o corte no eixo y, em (0, c); (3) as raízes, se existirem; (4) o vértice. E um ponto extra de graça: o espelho de (0, c) do outro lado do vértice.

f(x) = 2x² + 4x − 6
a = 2, b = 4, c = −6.
a = 2 > 0: boca pra cima  ·  c = −6: passa por (0, −6)
(1) e (2), só de olhar.
Δ = 16 − 4 · 2 · (−6) = 16 + 48 = 64  →  x = −4 ± 84
(3) As raízes. 4 · 2 · (−6) = −48, e menos com menos dá +48. √64 = 8 e 2a = 4.
x = 44 = 1   ou   x = −124 = −3
Corta o eixo x em (1, 0) e (−3, 0).
xv = −44 = −1  ·  yv = 2 − 4 − 6 = −8
(4) O vértice: (−1, −8). Conferindo: −1 é o meio de −3 e 1.
espelho de (0, −6): (−2, −6)
O 0 está 1 passo à direita do vértice (x = −1). O espelho fica 1 passo à esquerda: x = −2, na mesma altura.
Com esses 5 pontos, a parábola sai sozinha.
Robozinho perguntaUma parábola tem vértice (3, −2) e passa por (5, 6). Que outro ponto ela tem com certeza?

(1, 6): o 5 está 2 passos à direita do 3; o espelho fica 2 passos à esquerda, na mesma altura.

Robozinho perguntaSe a > 0 e o vértice está acima do eixo x, quantas raízes a função tem?

Nenhuma. A ponta é o ponto mais baixo, e ela já está acima do eixo. (Nesse caso o Δ dá negativo.)

Saiba mais: a forma do vértice

Toda parábola pode ser escrita como a(x − xv)² + yv. Exemplo: 2x² + 4x − 6 = 2(x + 1)² − 8. Lendo como transformação: o x² andou 1 pra esquerda, esticou 2 e desceu 8.

8. Inequações do 2º grau

Pra resolver ax² + bx + c > 0 (ou <, ≥, ≤): acha as raízes, imagina a parábola e vê onde ela fica acima do eixo (positiva) ou abaixo (negativa). Boca pra cima: negativa entre as raízes, positiva fora.

x² − 4x + 3 < 0
Pergunta: em que x a altura é negativa?
raízes: 1 e 3  ·  boca pra cima
As raízes vêm da etapa 5. a = 1 > 0.
O pedaço laranja é onde a parábola fica abaixo do eixo: entre 1 e 3.
1 < x < 3
É < e não ≤: nas raízes a altura é 0, que não é negativo. Por isso bolinha aberta.
x² − 4x + 3 ≥ 0  →  x ≤ 1 ou x ≥ 3
A pergunta contrária: fora das raízes, agora incluindo elas (≥ aceita o zero). Bolinha fechada.
Robozinho pergunta−x² + 2x + 3 > 0. As raízes são −1 e 3 e a boca é pra baixo. Onde é positiva?

Boca pra baixo fica acima do eixo entre as raízes: −1 < x < 3.

Robozinho perguntaQuando x² + 1 > 0?

Sempre: x² nunca é negativo, então x² + 1 é pelo menos 1. A resposta é todo x real.

Saiba mais: quadro de sinais

Outro jeito: escrever como a(x − x₁)(x − x₂) e fazer um quadro com o sinal de cada parênteses. Dá a mesma resposta, e é o jeito que vai servir em Equações e inequações com funções, quando aparecem frações e produtos maiores.

9. Receita

  1. Reta f(x) = ax + b: b é onde corta o eixo y; a é quanto sobe por passo (negativo: desce). Por dois pontos: a = (y₂ − y₁) ÷ (x₂ − x₁), depois acha b com um ponto.
  2. Equação do 1º grau: o que faz de um lado, faz do outro. Inequação: igual, mas multiplicar ou dividir por negativo vira o sinal.
  3. Parábola f(x) = ax² + bx + c: a > 0 boca pra cima, a < 0 pra baixo; c é onde corta o eixo y.
  4. Raízes: deixa "= 0" de um lado; Δ = b² − 4ac; x = (−b ± √Δ) ÷ 2a. Sem b ou sem c, dá pra resolver sem fórmula (sem dividir por x!).
  5. Vértice: x = −b ÷ 2a (o meio das raízes); y = f(desse x). Cresce de um lado, decresce do outro.
  6. Inequação do 2º grau: raízes + desenho da boca. Boca pra cima: negativa entre as raízes, positiva fora. ≤ e ≥ incluem as raízes.

O laboratório da parábola

Mexa nos coeficientes de y = ax² + bx + c e veja as raízes, o vértice e o Δ mudarem na hora. Coloque a = 0 pra ver a parábola virar reta. No desafio, faça o desenho verde cair em cima do laranja.
