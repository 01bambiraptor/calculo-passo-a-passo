1. Função exponencial: multiplicar a cada passo

Na função exponencial f(x) = ax (com a > 0 e a ≠ 1), o x está no expoente. A cada passo de 1 no x, o valor é multiplicado por a (na reta, era somado). E a0 = 1 sempre.

f(x) = 3x
A base é 3, e o x mora lá em cima.
x: 0, 1, 2, 3  →  1, 3, 9, 27
Cada passo multiplica por 3. Repara que 3⁰ = 1: qualquer base elevada a zero dá 1.
3−1 = 13    3−2 = 19
Pra trás, divide por 3. Expoente negativo vira "um sobre": 3⁻² = 1/3².
31/2 = √3 ≈ 1,73
Com expoente fração, é raiz (Raiz quadrada e módulo, etapa 2).
2x  vs  2x  com x = 10:   20  vs  1024
Somar sempre o mesmo é crescimento de reta. Multiplicar sempre pelo mesmo é exponencial, e explode bem mais rápido.
Robozinho perguntaQuanto é 50? E 5−1?

1 e 1/5.

Robozinho perguntaUma população dobra todo ano e começa com 100. Quanto tem depois de 3 anos?

100 · 2 · 2 · 2 = 100 · 2³ = 800. A função é 100 · 2^t.

Saiba mais: por que a base não pode ser 1 nem negativa

Com base 1, dá sempre 1: vira constante. Com base negativa, (−2)^(1/2) seria √(−2), que não existe: a função ficaria cheia de buracos.

2. O gráfico da exponencial

Todo gráfico de ax passa por (0, 1) e fica sempre acima do eixo x, chegando perto dele sem encostar (assíntota y = 0). Base maior que 1: cresce. Base entre 0 e 1: decresce. Domínio: todos os reais; imagem: (0, ∞).

y = 3^x: na esquerda, colado no eixo; na direita, dispara.
Verde: (1/3)^x. É o espelho de 3^x pelo eixo y: base entre 0 e 1 decresce.
3x + 1
O + 1 de fora sobe tudo: passa por (0, 2), e a assíntota sobe junto, pra y = 1.
A linha tracejada é a nova assíntota.
Robozinho perguntaOnde está a assíntota de 2^x − 5?

Em y = −5 (o − 5 desce tudo, inclusive a assíntota).

Robozinho perguntaA exponencial 2^x pode dar zero ou negativo?

Nunca: sempre positiva. Por isso a imagem é (0, ∞).

Saiba mais: o número e

A base mais usada em Cálculo é o número e ≈ 2,718. A função e^x tem uma propriedade especial: a inclinação dela em cada ponto é igual ao próprio valor. Você vai ver isso em derivadas.

3. Logaritmo: a pergunta "elevado a quanto?"

loga b é o expoente que faz a virar b: a elevado a quanto dá b? Ou seja, loga b = y quer dizer ay = b. Só existe com b > 0 (e base a > 0, ≠ 1).

log3 81 = ?
Pergunta: 3 elevado a quanto dá 81?
34 = 81  →  log3 81 = 4
3 · 3 · 3 · 3 = 81.
log5 125 = −2
Porque 5⁻² = 1/25. Log pode dar negativo: o que não pode ser negativo é o número de dentro.
loga 1 = 0    loga a = 1
Qualquer base elevada a 0 dá 1; elevada a 1 dá ela mesma.
log2 (−4)  ∉ ℝ
Nenhuma potência de 2 dá negativo (etapa 2): não existe.
Robozinho perguntaQuanto é log₁₀ 1000?

3, porque 10³ = 1000. (Log na base 10 conta os zeros.)

Robozinho perguntaE log₇ 7?

1, porque 7¹ = 7.

Saiba mais: log e exponencial se desfazem

aloga x = x e loga ax = x. Uma é a inversa da outra (Composição e inversa).

4. Log sem calculadora: tudo na mesma base

Quando a base e o número de dentro são potências do mesmo número, escreve os dois como potência dele e compara os expoentes.

log27 9 = y  →  27y = 9
Traduz o log pra potência.
27 = 33    9 = 32
Os dois são potências de 3.
(33)y = 32  →  33y = 32
Potência de potência: multiplica os expoentes.
3y = 2  →  y = 23
Mesma base dos dois lados: os expoentes têm que ser iguais.
log12 8:   12 = 2−1, 8 = 23  →  −y = 3  →  y = −3
Base fração funciona igual: 1/2 é 2⁻¹.
Robozinho perguntaQuanto é log₄ 2?

4 = 2², então 2^(2y) = 2¹ e y = 1/2. (De fato, 4^(1/2) = √4 = 2.)

Robozinho perguntaE log₉ (1/3)?

9 = 3² e 1/3 = 3⁻¹: 2y = −1, y = −1/2.

Saiba mais: conferindo a resposta

Sempre dá pra conferir voltando pra potência: log₂₇ 9 = 2/3 confere se 27^(2/3) = 9. E 27^(2/3) = (∛27)² = 3² = 9 ✔.

5. As propriedades do log

Log transforma multiplicação em soma: log(xy) = log x + log y; divisão em subtração: log(x/y) = log x − log y; e potência em multiplicação: log(xⁿ) = n · log x. (Tudo na mesma base.)

log2 (8 · 4) = log2 8 + log2 4 = 3 + 2 = 5
Confere: 8 · 4 = 32 = 2⁵.
log3 819 = 4 − 2 = 2
Confere: 81/9 = 9 = 3².
log2 85 = 5 · log2 8 = 5 · 3 = 15
O expoente desce e multiplica. É a mais usada pra resolver equação.
log2 (8 + 8) ≠ log2 8 + log2 8
Não existe regra pra soma dentro do log: log₂ 16 = 4, e 3 + 3 = 6.
Robozinho perguntaEscreva 2 log₃ 5 como um log só.

log₃ 5² = log₃ 25.

Robozinho perguntalog₁₀ 2 ≈ 0,301. Quanto é log₁₀ 20?

log 20 = log(2 · 10) = log 2 + log 10 ≈ 0,301 + 1 = 1,301.

Saiba mais: de onde vem a primeira regra

Se a^m = x e a^n = y, então xy = a^m · a^n = a^(m+n). Logo log(xy) = m + n = log x + log y. É a regra "multiplica potências, soma expoentes" vista de trás pra frente.

6. Mudança de base e a calculadora

A calculadora só tem log na base 10 (log) e na base e (ln). Pra qualquer outra base, usa a mudança de base: loga b = ln bln a (ou com log nos dois, dá igual).

log2 7 = ln 7ln 2
A base vai pra baixo, o número de dentro fica em cima.
= 1,94590,6931 ≈ 2,807
Na calculadora: ln 7 ≈ 1,9459 e ln 2 ≈ 0,6931.
22,807 ≈ 7 ✔
Faz sentido: está entre 2² = 4 e 2³ = 8, mais perto do 8.
log8 x = log2 xlog2 8 = log2 x3
Também serve pra trocar uma base por outra sem calculadora.
Robozinho perguntaComo calcular log₅ 12 na calculadora?

ln 12 ÷ ln 5 (ou log 12 ÷ log 5). Dá ≈ 1,544.

Robozinho perguntaQuanto é log₉ x escrito na base 3?

log₃ x ÷ log₃ 9 = log₃ x ÷ 2.

Saiba mais: por que funciona

Se y = log_a b, então a^y = b. Tirando ln dos dois lados: y · ln a = ln b (a regra da potência). Logo y = ln b / ln a.

7. O gráfico do log

loga x é a inversa de ax: o gráfico é o espelho pela reta y = x. Passa por (1, 0), só existe pra x > 0 e cola no eixo y sem encostar (assíntota x = 0). Base maior que 1: cresce, bem devagar.

x: 13, 1, 3, 9  →  log3 x: −1, 0, 1, 2
Escolhendo potências de 3, as contas são de cabeça.
Pra subir 1, o x precisa triplicar: cresce cada vez mais devagar.
Verde: log₃ x. Laranja: 3^x. Espelhos pela reta tracejada y = x. O (0, 1) de um vira o (1, 0) do outro.
domínio: x > 0  ·  imagem: todos os reais
Trocou com a exponencial (a inversa troca domínio e imagem).
Robozinho perguntaOnde está a assíntota de log₂(x − 3)?

Em x = 3 (o − 3 de dentro anda 3 pra direita). E o domínio vira x > 3.

Robozinho perguntalog₂ x é negativo pra que valores de x?

Pra 0 < x < 1 (entre 0 e 1 a curva fica embaixo do eixo).

Saiba mais: base entre 0 e 1

log_(1/2) x decresce: é o espelho de log₂ x pelo eixo x. De fato, log_(1/2) x = −log₂ x (é a questão 2 da Lista 9, nos exercícios).

8. Equações exponenciais

Se dá pra escrever os dois lados na mesma base, iguala os expoentes. Se não dá, aplica log nos dois lados pra "descer" o x do expoente.

3x − 1 = 27
O x está no expoente.
3x − 1 = 33
27 = 3³: agora os dois lados têm base 3.
x − 1 = 3  →  x = 4
Mesma base: expoentes iguais. Confere: 3³ = 27 ✔.
2x = 5
Agora 5 não é potência de 2.
x = log2 5 = ln 5ln 2 ≈ 2,322
Pela definição de log (2 elevado a quanto dá 5?), e a calculadora pela mudança de base.
Robozinho perguntaResolva 4^x = 8.

4 = 2² e 8 = 2³: 2x = 3, x = 3/2.

Robozinho perguntaE 10^x = 7?

x = log₁₀ 7 ≈ 0,845.

Saiba mais: exponencial dos dois lados com bases diferentes

Em 2 · 3^x = 3 · 2^x, aplica ln dos dois lados e usa as propriedades: ln 2 + x ln 3 = ln 3 + x ln 2. Junta os x de um lado: x(ln 3 − ln 2) = ln 3 − ln 2, então x = 1. (É a 6h da Lista 8.)

9. Receita

  1. a^x: cada passo multiplica por a. a⁰ = 1, a⁻ⁿ = 1/aⁿ, a^(1/n) = raiz.
  2. Gráfico de a^x: passa por (0, 1), assíntota y = 0, sempre positiva. a > 1 cresce; 0 < a < 1 decresce.
  3. log_a b = y quer dizer a^y = b. Só com b > 0.
  4. Sem calculadora: escreve base e número como potências do mesmo número e compara expoentes.
  5. Propriedades: log(xy) = log x + log y; log(x/y) = log x − log y; log(xⁿ) = n log x.
  6. Calculadora: log_a b = ln b ÷ ln a.
  7. Gráfico de log_a x: passa por (1, 0), assíntota x = 0, só x > 0.
  8. Equação: mesma base → iguala expoentes; senão, aplica log.
