1. Raiz quadrada: o número que, ao quadrado, dá

√a é o número maior ou igual a zero que, ao quadrado, dá a. Nos reais, ela só existe pra a ≥ 0, e o resultado nunca é negativo.

√9 = 3
Porque 3² = 9, e 3 não é negativo.
(−3)² = 9 também,  mas  √9 ≠ −3
A raiz escolhe sempre a resposta não negativa. É uma regra, pra que √ seja função (uma saída só pra cada entrada).
x² = 9  →  x = 3  ou  x = −3
Equação é outra coisa: a pergunta é "quem ao quadrado dá 9?", e são dois números. O ± aparece na hora de resolver a equação, não dentro do √.
√−4  ∉ ℝ
Nenhum número real ao quadrado dá negativo.
√2 ≈ 1,414
A maioria das raízes não é exata: fica escrita com √.
Robozinho perguntaQuanto é √0? E √(1/4)?

0, e 1/2 (porque (1/2)² = 1/4).

Robozinho perguntaSe x² = 16, então x = 4?

Não só: x = 4 ou x = −4. Mas √16 é só 4.

Saiba mais: pode separar? às vezes

√a · b = √a · √b e √ab = √a√b (com a, b ≥ 0). Mas soma não separa: √(9 + 16) = √25 = 5, enquanto √9 + √16 = 3 + 4 = 7.

2. Outras raízes e o expoente fração

n√a é o número que, elevado a n, dá a. Índice ímpar (3, 5...) aceita negativo. Índice par (2, 4...) só aceita a ≥ 0. E raiz é potência com expoente fração: a1/n = n√a.

3√8 = 2
Porque 2³ = 2 · 2 · 2 = 8.
3√−8 = −2
(−2)³ = −8. Com expoente ímpar o sinal sobrevive, então dá pra voltar.
4√16 = 2    4√−16 ∉ ℝ
Expoente par sempre dá resultado não negativo: ninguém elevado a 4 dá −16.
161/4 = 4√16 = 2
Expoente fração: o número de baixo da fração é o índice da raiz.
82/3 = (3√8)² = 2² = 4
O de cima é a potência. Fazendo a raiz primeiro, os números ficam pequenos.
Robozinho perguntaQuanto é 27^(1/3)? E (−27)^(1/3)?

3 e −3 (índice 3 é ímpar, aceita negativo).

Robozinho perguntaE 9^(−1/2)?

O menos no expoente vira "um sobre": 1 ÷ 9^(1/2) = 1 ÷ √9 = 1/3.

Saiba mais: por que a1/2 = √a

Pela regra das potências, (a1/2)² = a1/2 · 2 = a¹ = a. Então a1/2 é um número que ao quadrado dá a: é a raiz.

3. Domínio de função com raiz

Com raiz de índice par, o que está dentro tem que ser ≥ 0. Pra achar o domínio, resolve essa inequação. Atenção ao que está dentro e ao que está fora da raiz.

f(x) = √x + 3
Quero saber quais x podem entrar.
x + 3 ≥ 0  →  x ≥ −3
O de dentro não pode ser negativo.
D(f) = [−3, ∞)
Bolinha fechada: no −3 dá √0 = 0, que existe.
g(x) = √6 − 3x:   6 − 3x ≥ 0 → −3x ≥ −6 → x ≤ 2
Dividir por −3 vira o sinal: é uma inequação (Funções do 1º e 2º grau, etapa 3).
h(x) = √x + 3  →  x ≥ 0
Agora o + 3 está fora da raiz: só o x precisa ser ≥ 0. A barra de cima da raiz mostra até onde vai o "dentro".
Robozinho perguntaQual o domínio de ∛(x − 7)?

Todos os reais: índice ímpar aceita negativo.

Robozinho perguntaE de 1/√(x − 2)?

x − 2 > 0 (maior, não maior ou igual): no x = 2 a raiz dá 0, e não pode dividir por 0. Então x > 2.

Saiba mais: 2º grau dentro da raiz

Em √(x² − 4), resolve x² − 4 ≥ 0 pelo desenho da parábola (Funções do 1º e 2º grau, etapa 8): x ≤ −2 ou x ≥ 2.

4. O gráfico da raiz

O gráfico de √x começa em (0, 0) e sobe cada vez mais devagar. É metade de uma parábola deitada: a inversa de x² (com x ≥ 0). As transformações de Gráficos valem igual.

x: 0, 1, 4, 9  →  √x: 0, 1, 2, 3
Escolhendo quadrados perfeitos, as contas saem exatas.
Ligando os pontos. Pra subir de 2 pra 3, o x vai de 4 até 9: cada degrau custa mais passos.
Verde: √x. Laranja: x² com x ≥ 0. São espelhos pela reta tracejada y = x: uma desfaz a outra (são inversas).
√x − 2 + 1
Dentro, −2: anda 2 pra direita. Fora, +1: sobe 1. O começo vai pra (2, 1).
Tracejado: √x. Verde: √(x − 2) + 1.
Robozinho perguntaOnde começa o gráfico de √(x + 1) − 2?

Em (−1, −2): o + 1 de dentro anda 1 pra esquerda e o − 2 de fora desce 2.

Robozinho perguntaQual a imagem de √x?

[0, ∞): a raiz nunca dá negativo, e dá qualquer número ≥ 0.

Saiba mais: e a raiz cúbica?

∛x existe pra todo x e passa pela origem, deitada como um "S": é a inversa de x³. Nos negativos, fica embaixo do eixo.

5. Módulo: a distância até o zero

|x| (módulo, ou valor absoluto) é a distância de x até o zero na reta. Distância nunca é negativa. A regra: se x ≥ 0, |x| = x; se x < 0, |x| = −x (tira o sinal).

|5| = 5    |−5| = 5
Os dois estão a 5 passos do zero.
Na reta: os dois caminhos até o zero têm o mesmo tamanho.
|x| = x  se x ≥ 0   ·   |x| = −x  se x < 0
A fórmula tem duas partes.
|−3| = −(−3) = 3
O "−x" assusta, mas quando x é negativo, −x é positivo.
|2 − 7| = |−5| = 5
Primeiro a conta de dentro, depois tira o sinal.
|a − b| = distância entre a e b
|2 − 7| = 5: de 2 até 7 são 5 passos. Essa leitura vai resolver equações (etapa 8).
Robozinho perguntaQuanto é |−1/2|?

1/2.

Robozinho pergunta|x| pode dar negativo?

Nunca. E só dá 0 quando x = 0.

Robozinho perguntaE |3 − π|?

π ≈ 3,14 é maior que 3, então 3 − π é negativo. Tirando o sinal: |3 − π| = π − 3.

Saiba mais: multiplicação sim, soma não

|a · b| = |a| · |b| sempre. Já |a + b| pode ser menor que |a| + |b|: |3 + (−5)| = 2, enquanto |3| + |−5| = 8. Isso se chama desigualdade triangular, e aparece em limites.

6. √(x²) = |x|: onde raiz e módulo se encontram

√x² = |x|, e não x. A raiz não pode dar negativo, mas o x pode ser negativo. Vale pra todo índice par: 4√x⁴ = |x|. Com índice ímpar não precisa: 3√x³ = x.

x = 3:   √3² = √9 = 3
Com x positivo, volta o próprio x.
x = −3:   √(−3)² = √9 = 3
Com x negativo, volta 3, e não −3.
√x² = |x|
O módulo é exatamente "x sem o sinal".
√x² y⁴ = |x| y²
O y² já é ≥ 0, não precisa de módulo. Só precisa quem sai da raiz com expoente ímpar (o x saiu como x¹).
3√(−2)³ = 3√−8 = −2
Índice ímpar: o sinal volta direitinho, sem módulo.
Robozinho perguntaQuanto é √((x − 5)²)?

|x − 5|.

Robozinho perguntaE √(x⁶)?

x⁶ = (x³)², então √(x⁶) = |x³|, que é o mesmo que |x|³. Precisa do módulo porque x³ pode ser negativo.

Saiba mais: e (√x)²?

(√x)² = x, mas só pra x ≥ 0 (senão √x nem existe). A ordem importa: √(x²) existe pra todo x e dá |x|; (√x)² só existe pra x ≥ 0 e dá x.

7. O gráfico do módulo

O gráfico de |x| é um V com a ponta em (0, 0): igual a y = x na direita e a y = −x na esquerda. As transformações movem a ponta: |x − h| + k tem a ponta em (h, k).

x: −2, −1, 0, 1, 2  →  |x|: 2, 1, 0, 1, 2
Os valores se repetem dos dois lados do zero.
Um V. Na direita é a reta y = x; na esquerda, a reta y = −x.
|x − 2|: o − 2 de dentro anda 2 pra direita. Ponta em (2, 0).
|x| − 1: o − 1 de fora desce 1. Ponta em (0, −1), e agora corta o eixo x em −1 e 1.
|x² − 4|: o pedaço da parábola que estava embaixo do eixo vai pra cima, como num espelho.
Robozinho perguntaOnde fica a ponta de |x + 3| − 2?

Em (−3, −2).

Robozinho perguntaOnde o gráfico de |x| − 1 corta o eixo x?

Onde |x| − 1 = 0, ou seja |x| = 1: x = 1 ou x = −1.

Saiba mais: o V são duas retas

|x − 2| = x − 2 quando x ≥ 2, e = −x + 2 quando x < 2. São duas retas, cada uma valendo de um lado da ponta. É uma função "definida por partes".

8. Equações e inequações com módulo

Pense em distância. |x − 2| = 3: os números a distância 3 do 2 (o 5 e o −1). |x − 2| < 3: os que estão mais perto que isso (entre −1 e 5). |x − 2| > 3: os mais longe (fora).

|x − 2| = 3
Pergunta: quem está a 3 passos do 2?
x = 2 + 3 = 5  ou  x = 2 − 3 = −1
Um passo de 3 pra cada lado.
x − 2 = 3  ou  x − 2 = −3
O mesmo pela regra: o de dentro vale 3 ou −3 (os dois têm módulo 3).
|x − 2| < 3  →  −1 < x < 5
Mais perto do 2 que 3 passos: entre os dois. Bolinha aberta (exatamente 3 não é menor que 3).
|x − 2| ≥ 3  →  x ≤ −1  ou  x ≥ 5
A pergunta contrária: longe, pros dois lados. Agora as pontas entram.
|x + 1| = −2  →  sem solução
Módulo nunca é negativo.
Robozinho perguntaResolva |x| = 4.

x = 4 ou x = −4.

Robozinho perguntaE |x + 1| < 2?

|x + 1| = |x − (−1)|: distância até o −1, menor que 2. Então −3 < x < 1.

Saiba mais: quando tem número multiplicando o x

Em |2x − 1| = 5, a regra "o de dentro vale 5 ou −5" é mais segura que a ideia de distância: 2x − 1 = 5 ou 2x − 1 = −5, então x = 3 ou x = −2.

9. Receita

  1. √a é o número ≥ 0 que ao quadrado dá a. √9 = 3 (só). Já x² = 9 tem duas respostas: ±3.
  2. Índice par: só de número ≥ 0. Índice ímpar: de qualquer número. a^(m/n) = raiz n-ésima de a elevada a m.
  3. Domínio com raiz par: o de dentro ≥ 0 (cuidado com o que está dentro e o que está fora; dividir por negativo vira o sinal).
  4. |x| = distância até o zero. |a − b| = distância entre a e b.
  5. √(x²) = |x|. Ao tirar da raiz par, quem sai com expoente ímpar ganha módulo.
  6. Gráficos: √(x − h) + k começa em (h, k); |x − h| + k tem a ponta em (h, k).
  7. |x − c| = r: x = c ± r (se r ≥ 0). < r: entre c − r e c + r. > r: fora.

O laboratório da raiz e do módulo

Escolha a função de base, mexa no número de dentro (h) e no de fora (k), e veja onde o gráfico começa (raiz) ou onde fica a ponta (módulo). No desafio, faça o verde cair em cima do laranja.
