1. Potência com qualquer expoente

A regra (xⁿ)′ = n·xⁿ⁻¹ vale pra expoente negativo e fração também. O truque é reescrever antes: 1/xⁿ = x⁻ⁿ e raiz = expoente fração (√x = x1/2, ∛x = x1/3).

5x2  =  5x−2
Primeiro passa o x de baixo pra cima: o expoente troca de sinal.
(5x−2)′ = 5 · (−2)x−3 = −10x−3 = −10x3
O −2 desce e o expoente diminui 1: −2 − 1 = −3.
√x = x1/2  →  12x−1/2 = 12√x
1/2 − 1 = −1/2. E x elevado a −1/2 é 1 sobre √x.
∛(x²) = x2/3  →  23x−1/3
Raiz de índice 3 do x²: o 2 fica em cima e o 3 embaixo.
Robozinho perguntaReescreva 1/x como potência e derive.

x⁻¹ → −1·x⁻² = −1/x². Bate com o que saiu pela definição em Derivadas.

Robozinho perguntaQuanto é 2/5 − 1?

−3/5. É o que sobra no expoente ao derivar x2/5.

Saiba mais: de onde vêm as regras de expoente

x⁻ⁿ = 1/xⁿ e xp/q = raiz de índice q de xp são as regras de Exponenciais e log. A derivada só funciona com a potência já escrita assim.

2. Regra do produto

A derivada de um produto não é o produto das derivadas. A regra é: (f·g)′ = f′·g + f·g′ (deriva um, mantém o outro; depois troca e soma).

(3x − 1)(x² + 2)
Chamando f = 3x − 1 e g = x² + 2.
f′ = 3    g′ = 2x
Deriva cada pedaço separado.
3 · (x² + 2) + (3x − 1) · 2x
f′·g + f·g′.
3x² + 6 + 6x² − 2x = 9x² − 2x + 6
Distributiva e junta os termos parecidos.
conferindo: (3x − 1)(x² + 2) = 3x3 − x² + 6x − 2  →  9x² − 2x + 6 ✔
Expandindo antes (o jeito de Derivadas) dá o mesmo.
Robozinho perguntaSe f′·g′ fosse a regra, quanto daria (x · x)′?

1 · 1 = 1. Mas x · x = x², cuja derivada é 2x. Por isso a regra precisa das duas parcelas.

Robozinho perguntaDerive x · (x + 5) pela regra do produto.

1·(x + 5) + x·1 = 2x + 5.

Saiba mais: por que soma de duas parcelas

Pense num retângulo de lados f e g. Se os dois lados crescem um pouquinho, a área ganha uma faixa f′·g (de um lado) e outra f·g′ (do outro). O cantinho f′·g′ é tão pequeno que some no limite.

3. Regra do quociente

Para uma divisão: (f/g)′ = (f′·g − f·g′) / g². Ordem importa (é subtração): começa pela derivada de cima. Embaixo, o de baixo ao quadrado.

x + 1x − 3
f = x + 1 (cima), g = x − 3 (baixo).
f′ = 1    g′ = 1
As duas derivadas.
1 · (x − 3) − (x + 1) · 1(x − 3)²
f′·g − f·g′, tudo sobre g².
x − 3 − x − 1(x − 3)² = −4(x − 3)²
Cuidado com o sinal: o menos troca o sinal dos DOIS termos de (x + 1).
Robozinho perguntaQual a derivada de 1/x pelo quociente?

(0·x − 1·1)/x² = −1/x². Igual à etapa 1.

Robozinho perguntaO denominador g² pode ser expandido?

Pode, mas normalmente deixa ao quadrado: fica mais limpo e mostra onde a função não existe.

Saiba mais: às vezes dá pra fugir do quociente

Se o de baixo é um termo só, como (x² + 3)/x, divide antes: x + 3/x = x + 3x⁻¹. Aí é só potência. O exercício c, mais abaixo, usa isso.

4. Exponencial

A função eˣ é a única que é a própria derivada: (eˣ)′ = eˣ. Para outra base: (aˣ)′ = ln(a) · aˣ.

(ex)′ = ex
A inclinação em cada ponto é igual à altura do gráfico.
Em x = 1 a altura é e ≈ 2,72, e a tangente tem inclinação 2,72 também.
(5x)′ = ln 5 · 5x
Base 5: aparece o ln 5 multiplicando. Com a = e, ln e = 1, e volta a primeira regra.
(4ex − 2x)′ = 4ex − ln 2 · 2x
Número multiplicando e soma continuam valendo.
Robozinho perguntaDerive 7eˣ + x².

7eˣ + 2x.

Robozinho perguntaE (1/2)ˣ? O que acontece com o sinal?

ln(1/2) · (1/2)ˣ. Como ln(1/2) é negativo, a derivada é negativa: a função decresce.

Saiba mais: cuidado: xⁿ não é aˣ

Em x⁵ a variável está na base: regra da potência (5x⁴). Em 5ˣ ela está no expoente: regra da exponencial (ln 5 · 5ˣ). O exercício "β(x) = x⁵ + 5ˣ" da lista mistura os dois de propósito.

5. Logaritmo

(ln x)′ = 1/x. Em outra base: (logₐ x)′ = 1/(x · ln a). Antes de derivar, vale usar as propriedades do log pra tirar expoentes: ln(xᵏ) = k · ln x.

(ln x)′ = 1x
Só existe pra x > 0.
(log₃ x)′ = 1x · ln 3
O ln da base vai pra baixo.
ln(x5) = 5 ln x  →  5x
Primeiro tira o expoente com a propriedade, depois deriva.
Em x = 1, 1/x = 1: a tangente a ln x ali é y = x − 1.
Robozinho perguntaQual a inclinação de ln x em x = 4?

1/4.

Robozinho perguntaDerive ln(∛x).

ln(x1/3) = (1/3) ln x → 1/(3x).

Saiba mais: por que 1/x

O ln é a inversa de eˣ (Composição e inversa). Inverter troca x com y no gráfico, então a inclinação vira o inverso: se eʸ tem inclinação eʸ = x, o ln tem inclinação 1/x.

6. Seno e cosseno

(sen x)′ = cos x e (cos x)′ = −sen x (com x em radianos). Só o cosseno ganha um menos.

Verde: sen x. Laranja tracejado: cos x. Onde o seno está no topo (inclinação 0), o cosseno vale 0.
(sen x)′ = cos x    (cos x)′ = −sen x
As duas regras.
(3 sen x + 5 cos x)′ = 3 cos x − 5 sen x
Número multiplicando fica; o menos aparece só no cosseno.
em x = 0:   3 · 1 − 5 · 0 = 3
cos 0 = 1 e sen 0 = 0 (Trigonometria).
Robozinho perguntaDerive −cos x.

−(−sen x) = sen x.

Robozinho perguntaQual a inclinação de sen x em x = π?

cos π = −1.

Saiba mais: por que radianos

A regra (sen x)′ = cos x sai de lim sen(h)/h = 1, que só é verdade com h em radianos. Em graus apareceria um π/180 a mais em todo lugar.

7. Regra da cadeia (função dentro de função)

Quando tem uma função dentro de outra, deriva a de fora (com o de dentro intacto) e multiplica pela derivada do de dentro: (f(g(x)))′ = f′(g(x)) · g′(x). Nas listas, o de dentro quase sempre é ax + b, e a regra vira "multiplica pelo a".

e5x
Fora: e□. Dentro: 5x (a composição de Composição e inversa).
e5x · 5 = 5e5x
eᵘ deriva pra eᵘ (com o mesmo 5x dentro); a derivada de 5x é 5.
sen(4x − 1)  →  cos(4x − 1) · 4 = 4 cos(4x − 1)
Fora: seno vira cosseno. Dentro: 4x − 1 deriva pra 4.
cos(−2x)  →  −sen(−2x) · (−2) = 2 sen(−2x)
Dois menos: o do cosseno e o −2 de dentro. Menos com menos dá mais.
(x² + 1)4  →  4(x² + 1)³ · 2x = 8x(x² + 1)³
Também vale com dentro maior: fora é potência, dentro x² + 1 deriva pra 2x.
Robozinho perguntaDerive e^(−x).

e^(−x) · (−1) = −e^(−x).

Robozinho perguntaDerive cos(x/2).

−sen(x/2) · 1/2.

Robozinho perguntaQual o erro mais comum aqui?

Esquecer de multiplicar pela derivada de dentro. Teste: (e^(3x))′ não é e^(3x), é 3e^(3x).

Saiba mais: a corrente de engrenagens

Se a engrenagem de dentro gira 5 vezes mais rápido que x, e a de fora responde à de dentro, as taxas se multiplicam. Por isso "cadeia": uma derivada vezes a outra.

8. Juntando: tangente com as funções novas

A receita da tangente é a mesma de Derivadas: y = f(a) + f′(a)(x − a). O que muda é que f(a) e f′(a) agora podem ter e, ln, π, √. Dá a resposta exata e, se a lista pedir, a aproximada na calculadora.

f(x) = sen x + x,   a = 0
Tangente em x = 0.
f(0) = 0 + 0 = 0    f′(x) = cos x + 1 → f′(0) = 1 + 1 = 2
Ponto (0, 0) e inclinação 2.
y = 0 + 2(x − 0) = 2x
A equação.
A reta encosta na curva na origem.
Robozinho perguntaTangente a eˣ em x = 0?

f(0) = 1 e f′(0) = 1: y = x + 1.

Robozinho perguntaSe a resposta for y = −(√3/2)x + 1, como fica aproximada?

√3/2 ≈ 0,87: y ≈ −0,87x + 1.

Saiba mais: quando a tangente fica deitada

Em sen x, a tangente fica deitada em x = π/2 (cos π/2 = 0): é o topo da onda. É o mesmo "f′ = 0 é pico ou vale" de Derivadas, etapa 7.

9. Receita

  1. Reescreve primeiro: 1/xⁿ = x⁻ⁿ, raiz = expoente fração, ln(xᵏ) = k ln x. Fração com um termo embaixo: divide.
  2. Tabela: (xⁿ)′ = n·xⁿ⁻¹ · (eˣ)′ = eˣ · (aˣ)′ = ln a · aˣ · (ln x)′ = 1/x · (logₐ x)′ = 1/(x ln a) · (sen x)′ = cos x · (cos x)′ = −sen x.
  3. Produto: f′g + fg′. Quociente: (f′g − fg′)/g².
  4. Cadeia: deriva a de fora com o de dentro intacto, vezes a derivada do de dentro. Com dentro ax + b: vezes a.
  5. Sinais: conte os menos (do cosseno, do número, do de dentro).
  6. Tangente: y = f(a) + f′(a)(x − a); dá a exata e, se pedirem, a aproximada.

O laboratório da derivada

Escolha uma função e mova o ponto. Em cima, a função com a tangente. Embaixo, o gráfico da inclinação: cada ponto laranja tem altura igual à inclinação da tangente. No desafio, descubra qual fórmula desenha o gráfico de baixo.
