Gráficos e transformações

Ler e desenhar gráficos, e o que somar, multiplicar ou trocar o sinal faz com o desenho.

Caminho principal

Em cada etapa: um resumo curto e a animação (ou as perguntas, no modo socrático). As caixinhas "saiba mais" são opcionais e não contam no progresso.

1. O gráfico é uma coleção de pontos

Cada ponto do gráfico é um par (entrada, saída): o ponto (a, b) está no gráfico quando f(a) = b. Pra desenhar, faz uma tabelinha com números fáceis e liga os pontos.

f(x) = √x
Vamos desenhar a raiz quadrada. Ela vai ser a nossa função de exemplo em todas as etapas.
x = 0, 1, 4  →  f(x) = 0, 1, 2
Escolho x com raiz exata: √0 = 0, √1 = 1, √4 = 2.
Marco os pontos (0, 0), (1, 1) e (4, 2).
Ligo com uma curva suave. Pra x negativo não tem desenho: não existe raiz de negativo (domínio x ≥ 0).
Robozinho perguntaO ponto (9, 3) está no gráfico de f(x) = √x? E o (9, −3)?

(9, 3) está: √9 = 3. O (9, −3) não: a raiz quadrada nunca dá negativo.

Robozinho perguntaNum gráfico, como eu leio f(2)?

Vou no x = 2 do eixo deitado, subo (ou desço) até encostar no desenho e vejo a altura. Essa altura é f(2).

Saiba mais: os "pontos-chave"

Nas próximas etapas, em vez de refazer a tabela, a gente pega uns poucos pontos-chave do gráfico original (o começo, os zeros, os picos) e vê pra onde cada um vai. O resto do desenho vai junto.

2. Somar fora: sobe ou desce

f(x) + c soma c em todas as saídas: o desenho inteiro sobe c (ou desce, se c for negativo). Cada ponto (a, b) vai pra (a, b + c).

√x  →  √x + 2
Somei 2 depois de calcular a raiz.
(0, 0) → (0, 2)    (4, 2) → (4, 4)
Cada saída ganha 2. As entradas (x) ficam iguais.
O desenho inteiro subiu 2. tracejado: √x original   verde: o novo
√x − 3  →  desce 3
Com sinal de menos, desce.
Robozinho perguntaO gráfico de f(x) + 5 fica onde, comparado com o de f?

5 unidades acima. Cada altura ganha 5.

Robozinho perguntaSe (1, 1) está no gráfico de √x, que ponto está no gráfico de √x − 3?

(1, −2): mesmo x, altura 1 − 3 = −2.

Saiba mais: o domínio não muda

Subir e descer não mexe nas entradas. Então o domínio continua o mesmo; só a imagem muda (a de √x + 2 é [2, ∞[).

3. Somar dentro: anda pro lado, ao contrário

f(x + c) mexe nas entradas: o desenho anda pro lado. E anda ao contrário do sinal: com + c vai c pra esquerda; com − c vai pra direita.

√x  →  √x + 3
Agora o 3 está dentro da raiz, junto com o x.
√x começa onde dentro vale 0: x = 0
A raiz começa no ponto em que o de dentro é zero.
√x + 3 começa onde x + 3 = 0: x = −3
Pro de dentro valer zero, agora o x tem que ser −3. O começo foi pra esquerda.
Tudo andou 3 pra esquerda: (0, 0) → (−3, 0) e (4, 2) → (1, 2). tracejado: √x original   verde: o novo
por quê?   f(1 + 3) = f(4)
A nova função faz em x = 1 o que a antiga fazia em x = 4. Ela chega 3 unidades antes. Por isso "+" vai pra esquerda.
Robozinho pergunta√x − 2 começa em que x?

Onde x − 2 = 0: x = 2. Andou 2 pra direita, mesmo com o sinal de menos.

Robozinho perguntaUma frase pra lembrar: mexer dentro do parênteses...?

...mexe no eixo x (deitado) e faz o contrário do que parece. Mexer fora mexe no eixo y e faz o que parece.

Saiba mais: o domínio anda junto

Como o desenho anda pro lado, o domínio anda também: √x tem domínio [0, ∞[ e √(x + 3) tem [−3, ∞[. A imagem não muda.

4. Multiplicar fora: estica ou achata

c · f(x) multiplica todas as alturas por c. Com c > 1, o desenho estica pra cima; com 0 < c < 1, achata. Os pontos com altura 0 (os zeros) não saem do lugar.

√x  →  3√x
Multiplico a saída por 3.
(4, 2) → (4, 6)    (1, 1) → (1, 3)    (0, 0) → (0, 0)
Cada altura vezes 3. O zero continua zero: 3 · 0 = 0.
Esticou na vertical, preso no zero. tracejado: √x original   verde: o novo
12√x:   (4, 2) → (4, 1)
Multiplicar por 1/2 corta as alturas pela metade: achata.
Robozinho perguntaSe o gráfico de f corta o eixo x em x = −3, onde corta o de 5f(x)?

No mesmo x = −3: 5 · 0 = 0. Esticar não move os zeros.

Robozinho perguntaE se o gráfico de f tem um pico de altura 2, qual a altura do pico de 5f(x)?

10.

Saiba mais: e multiplicar dentro?

f(2x) mexe nas entradas, então age na horizontal e ao contrário: o desenho encolhe pela metade na direção do eixo x (chega na mesma altura com metade do x). Aparece bastante em trigonometria.

5. Sinal de menos: espelho

−f(x) (menos fora) troca o sinal das alturas: espelho no eixo x (vira de cabeça pra baixo). f(−x) (menos dentro) troca as entradas: espelho no eixo y (vira pro outro lado).

−√x:   (4, 2) → (4, −2)
Menos fora: cada altura troca de sinal.
Virou de cabeça pra baixo (espelho no eixo x). tracejado: √x original   verde: o novo
√−x:   (4, 2) → (−4, 2)
Menos dentro: agora quem entra negativo é que funciona. √(−(−4)) = √4 = 2.
Virou pro outro lado (espelho no eixo y). tracejado: √x original   verde: o novo
Robozinho pergunta√−x existe pra x = −9? E pra x = 9?

Pra x = −9 sim: √(−(−9)) = √9 = 3. Pra x = 9 não: √(−9). O domínio virou ]−∞, 0].

Robozinho perguntaUma função par fica igual depois do espelho f(−x)?

Fica: par quer dizer exatamente f(−x) = f(x), gráfico simétrico no eixo y (assunto de Funções).

Saiba mais: os dois espelhos juntos

−f(−x) espelha nos dois eixos: é o mesmo que girar meia volta em torno da origem. Uma função ímpar fica igual depois disso.

6. Várias transformações: a ordem importa

Quando tem várias, faz uma de cada vez, seguindo a ordem das contas: primeiro o que está dentro (horizontal), depois multiplicação fora, por último soma fora. Trocar a ordem pode mudar o resultado.

2√x − 1 + 3
Três mudanças na mesma fórmula. Vamos uma de cada vez, levando o ponto (4, 2) de √x.
√x − 1:   (4, 2) → (5, 2)
1º, dentro: − 1 no x anda 1 pra direita.
2√x − 1:   (5, 2) → (5, 4)
2º, multiplicar fora: altura vezes 2.
2√x − 1 + 3:   (5, 4) → (5, 7)
3º, somar fora: sobe 3. Conferindo na fórmula: 2√(5 − 1) + 3 = 2 · 2 + 3 = 7.
2√x + 1  ≠  2(√x + 1)
Ordem: "esticar e depois subir 1" dá 2√x + 1. "Subir 1 e depois esticar" dá 2(√x + 1) = 2√x + 2, que fica 1 mais alto.
Robozinho perguntaEm √x + 4 − 1, quais são as transformações?

4 pra esquerda (dentro) e 1 pra baixo (fora).

Robozinho perguntaOnde começa o desenho de √(x + 4) − 1?

O √x começa em (0, 0). Andando 4 pra esquerda e 1 pra baixo: (−4, −1).

Saiba mais: a ligação com composição

Cada transformação é uma máquina a mais na fila: 2√(x − 1) + 3 é "tira 1", depois "raiz", depois "dobra", depois "soma 3". É por isso que a ordem importa, igual na composição.

7. Um sobre f: o gráfico de 1/f(x)

Em 1f(x), cada altura vira o seu inverso. Três regras: onde f = 0, o 1/f não existe e o desenho dispara (assíntota em pé); onde f é grande, 1/f é pequeno (e vice-versa); onde f = 1 ou −1, fica igual.

f(x) = x − 1  →  1x − 1
Uma reta, e o inverso dela.
x = 1:   10 não existe
Onde a reta corta o eixo (f = 0), o inverso não existe.
x = 1,1:   10,1 = 10    x = 1,01:   10,01 = 100
Perto do zero da f, o inverso fica enorme: o desenho dispara pra cima.
x = 2:   f = 1 → 11 = 1    x = 5:   f = 4 → 14
Onde f vale 1, fica 1. Onde f é grande, o inverso é pequeno, chegando perto de zero.
Tracejado: f(x) = x − 1. Verde: 1/f. A linha em pé em x = 1 é a assíntota: o desenho chega perto dela sem nunca encostar.
Robozinho perguntaSe f(3) = 2, quanto vale 1/f no x = 3? E se f(3) = −1/2?

1/2. E se f(3) = −1/2, então 1/f(3) = −2 (o inverso mantém o sinal).

Robozinho perguntaOnde estão as assíntotas em pé de 1/f?

Nos zeros da f, onde ela corta o eixo x.

Saiba mais: mais sobre assíntotas

As linhas que o desenho persegue sem encostar se chamam assíntotas. Elas voltam com tudo em polinômios e funções racionais, e o jeito certo de estudá-las é com limites, em Cálculo 1.

8. Receita das transformações

  1. Fora do parênteses mexe na altura (eixo y), e faz o que parece: f(x) + c sobe c; c · f(x) estica; −f(x) espelha no eixo x.
  2. Dentro do parênteses mexe no x, e faz o contrário: f(x + c) anda c pra esquerda; f(x − c), pra direita; f(−x) espelha no eixo y.
  3. Várias juntas: dentro primeiro; depois multiplicação fora; por último soma fora.
  4. Pra esboçar: pega os pontos-chave (começo, zeros, picos, cantos), leva cada um e liga com o mesmo formato.
  5. 1/f: zeros da f viram assíntotas; f = 1 fica; f grande vira pequeno.

O laboratório de transformações

Escolha a função e mexa nos três controles da fórmula y = a · f(x + h) + k. O tracejado é a f original. No desafio, faça o desenho verde cair em cima do laranja.

• Sempre erra o lado do f(x + c)? Pergunta "que x faz o de dentro dar zero?". Em f(x + 3), é x = −3: o que acontecia no 0 agora acontece no −3. Volte na etapa 3.

• Não sabe ler o gráfico dado? Revise como ler pontos e domínio em Funções.

• Confunde a ordem? Use o laboratório: mexa um controle de cada vez e veja o que muda.

• Travou no 1/f? Faz uma tabelinha: x, f(x), 1/f(x), com uns 5 valores. A etapa 7 mostra como.
