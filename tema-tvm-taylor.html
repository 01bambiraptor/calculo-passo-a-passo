1. Teorema de Rolle

Se f é contínua em [a, b], derivável em (a, b) e f(a) = f(b), então existe pelo menos um c entre a e b com f′(c) = 0. Quem sai de uma altura e volta pra mesma altura tem que "virar" em algum lugar.

f(x) = x² − 4x + 1   em [0, 4]
Confere as hipóteses: polinômio (contínuo e derivável), f(0) = 1 e f(4) = 16 − 16 + 1 = 1.
f′(x) = 2x − 4 = 0 → c = 2
O teorema garante que existe; aqui dá até pra achar.
Pontas na mesma altura (tracejada). No meio, a tangente fica deitada.
Robozinho pergunta|x| em [−1, 1] tem f(−1) = f(1). Existe c com f′(c) = 0?

Não. |x| não é derivável em 0, então Rolle não se aplica.

Robozinho perguntaRolle diz quantos c existem?

Pelo menos um. Pode haver vários.

Saiba mais: Rolle e raízes

Entre duas raízes de f existe uma raiz de f′. Por isso um polinômio de grau 3 tem no máximo 2 pontos de tangente deitada entre suas 3 raízes.

2. Teorema do Valor Médio

Se f é contínua em [a, b] e derivável em (a, b), existe c entre a e b com f′(c) = (f(b) − f(a))/(b − a): em algum instante a taxa instantânea é igual à taxa média. Rolle é o caso em que a média é 0.

f(x) = x3   em [0, 3]
Polinômio: as hipóteses valem.
média: 27 − 03 − 0 = 9
A inclinação da secante entre as pontas.
3c² = 9 → c² = 3 → c = √3 ≈ 1,73
−√3 está fora de (0, 3), então fica só √3.
Tracejada: a secante. Laranja: a tangente em c, paralela a ela.
100 km em 1 hora → em algum instante o velocímetro marcou 100 km/h
A versão do dia a dia: é por isso que radar de velocidade média funciona.
Robozinho perguntaTaxa média de x² em [1, 5]?

(25 − 1)/4 = 6. E 2c = 6 dá c = 3.

Robozinho perguntaSe f′(x) = 0 em todo um intervalo, o que o TVM diz?

Que f(b) − f(a) = 0 pra quaisquer a, b ali: f é constante.

Saiba mais: a cara de "desigualdade" do TVM

Escrito como f(b) − f(a) = f′(c)(b − a), ele mostra que se |f′| ≤ M, então |f(b) − f(a)| ≤ M|b − a|. É o exercício i, mais abaixo.

3. O que sai do Valor Médio

Três consequências que o curso inteiro usa: f′ = 0 num intervalo → f constante; f′ > 0 → f crescente (f′ < 0 → decrescente); e desigualdades entre funções.

a < b e f′(x) > 0  →  f(b) − f(a) = f′(c)(b − a) > 0
Os dois fatores são positivos. Então f(b) > f(a): crescente.
mostrar: ln(1 + x) < x para x > 0
Uma desigualdade com o TVM.
g(x) = x − ln(1 + x),   g(0) = 0,   g′(x) = 1 − 11 + x > 0
Pra x > 0, 1/(1 + x) < 1.
g crescente e g(0) = 0 → g(x) > 0 → ln(1 + x) < x
É o "sinal da derivada" de Derivadas, agora com prova.
Robozinho perguntaDuas funções com a mesma derivada em todo ℝ: o que se pode dizer?

A diferença delas tem derivada 0, então é constante: f = g + C. É a base de Primitivas.

Robozinho perguntaf′ ≥ 0 com f′ = 0 só em um ponto: f é crescente?

Sim. Um ponto isolado não estraga (como x³ em 0).

Saiba mais: isso é a base de Máximos e mínimos

"Onde f′ muda de sinal, f muda de subida pra descida" é uma consequência direta. O próximo assunto usa isso o tempo todo.

4. Regra de L'Hôpital

Se o limite dá 0/0 ou ∞/∞, dá pra trocar pela razão das derivadas: lim f/g = lim f′/g′ (se esse existir). Cuidado: é f′ sobre g′ separadas, não a derivada da fração.

limx→1 ln xx − 1
Substituindo: ln 1 = 0 e 1 − 1 = 0. É 0/0: pode usar.
limx→1 1/x1
Deriva em cima (1/x) e embaixo (1), separadamente.
= 1/11 = 1
Agora substitui.
limx→0 sen xx = limx→0 cos x1 = 1
O limite fundamental também sai assim (mas a prova de (sen x)′ = cos x usa ele, então é só conferência).
Robozinho perguntaPode usar L'Hôpital em (x + 1)/(x + 2) quando x → 0?

Não: dá 1/2 direto, não é 0/0. Usar ali daria 1/1 = 1, errado.

Robozinho perguntaE em (e^x − 1)/x em 0?

0/0: vira eˣ/1 → 1.

Saiba mais: por que funciona

Perto de a, com f(a) = g(a) = 0: f(x)/g(x) = (f(x) − f(a))/(g(x) − g(a)), e as duas diferenças se comportam como f′(a)(x − a) e g′(a)(x − a). O (x − a) corta. A prova certinha usa uma versão do TVM (o de Cauchy).

5. L'Hôpital mais de uma vez e com ∞/∞

Se depois de derivar ainda der 0/0 ou ∞/∞, deriva de novo. Antes de cada vez, confere que ainda é indeterminação. Com ∞/∞ vale igual, e mostra quem cresce mais rápido: ln x < potências < exponenciais.

limx→0 ex − 1 − xx²
Em 0: 1 − 1 − 0 = 0 em cima, 0 embaixo.
limx→0 ex − 12x
Ainda 0/0.
limx→0 ex2 = 12
Agora não é mais indeterminação: substitui.
limx→+∞ x²ex = limx→+∞ 2xex = limx→+∞ 2ex = 0
∞/∞ duas vezes. A exponencial ganha de qualquer potência.
Robozinho perguntaQuanto dá (ln x)/x no infinito?

(1/x)/1 → 0. O ln cresce mais devagar que x.

Robozinho perguntaE x³/eˣ?

Três vezes L'Hôpital: 6/eˣ → 0.

Saiba mais: quando L'Hôpital não ajuda

Em (x + sen x)/x no infinito, as derivadas dão (1 + cos x)/1, que fica oscilando. Mas o limite existe: é 1 (divide por x). L'Hôpital diz "se o novo limite existir"; se não existir, não conclui nada.

6. As outras indeterminações: 0·∞, ∞ − ∞ e 1^∞

L'Hôpital só aceita fração. As outras formas precisam ser arrumadas em fração primeiro: 0·∞ → passa um fator pra baixo como 1/ele; ∞ − ∞ → junta as frações; potências (1^∞, 0⁰, ∞⁰) → aplica ln, calcula, e no fim faz eresultado.

limx→0⁺ x ln x
0 · (−∞).
= limx→0⁺ ln x1/x = limx→0⁺ 1/x−1/x² = limx→0⁺ (−x) = 0
Virou −∞/∞. Derivando e simplificando a fração de frações.
limx→0⁺ xx:   ln(xx) = x ln x → 0
Forma 0⁰. Pelo ln, cai no limite de cima.
xx = eln(xx) → e0 = 1
Volta com a exponencial.
Robozinho perguntaPor que não dá pra fazer L'Hôpital direto em x·ln x?

Não é uma fração. Tem que escrever como fração antes.

Robozinho perguntaComo sai (1 + 1/x)^x → e por esse método?

ln = x·ln(1 + 1/x) = ln(1 + 1/x)/(1/x), 0/0. Derivando dá 1/(1 + 1/x) → 1. Então o limite é e¹.

Saiba mais: qual vai pra baixo?

Em 0·∞, normalmente desce o que fica mais fácil de derivar. Em x·ln x, descer o x (como 1/x) funciona; descer o ln (como 1/ln x) dá uma conta pior.

7. Polinômio de Taylor

A tangente é a melhor reta perto de a. O polinômio de Taylor de grau n é o melhor polinômio: ele tem as mesmas derivadas que f em a, até a n-ésima. Fórmula: Pₙ(x) = f(a) + f′(a)(x − a) + f″(a)/2! (x − a)² + … + f⁽ⁿ⁾(a)/n! (x − a)ⁿ.

cos x em a = 0:   cos 0 = 1, −sen 0 = 0, −cos 0 = −1, sen 0 = 0, cos 0 = 1
As derivadas do cosseno em 0, até a quarta: o ciclo cos, −sen, −cos, sen.
P₄(x) = 1 + 0 − 12!x² + 0 + 14!x4 = 1 − x²2 + x424
Cada derivada dividida pelo fatorial do grau. 2! = 2 e 4! = 24.
Verde: cos x. Tracejada: P₂. Laranja: P₄, que gruda por mais tempo.
cos(0,2) ≈ 1 − 0,02 + 0,0000667 = 0,9800667
O valor verdadeiro é 0,98006658: bate até a 7ª casa.
Robozinho perguntaQual o polinômio de Taylor de grau 1?

f(a) + f′(a)(x − a): a reta tangente.

Robozinho perguntaPor que o cosseno só tem potências pares?

As derivadas ímpares (±sen) valem 0 em 0. Faz sentido: cos é uma função par.

Saiba mais: série de Taylor

Continuando pra sempre (grau "infinito"), vira a série de Taylor. Pra eˣ, sen e cos, a série dá exatamente a função em qualquer x. É o que a questão 6 do treino pede pro arctg.

8. O erro: resto de Lagrange

Quanto o polinômio erra? f(x) − Pₙ(x) = f⁽ⁿ⁺¹⁾(c)/(n + 1)! · (x − a)ⁿ⁺¹, pra algum c entre a e x. Não sabemos o c, mas dá pra limitar: troca f⁽ⁿ⁺¹⁾(c) pelo maior valor possível dela no intervalo.

sen x ≈ x − x36   em x = 0,5
P₃ do seno em 0. (P₄ é igual, porque a 4ª derivada em 0 é sen 0 = 0.)
erro = f⁽⁵⁾(c)5! · 0,5⁵
Usando o resto do P₄ (dá uma conta melhor): n + 1 = 5.
|f⁽⁵⁾(c)| = |cos c| ≤ 1  →  |erro| ≤ 0,03125120 ≈ 0,00026
A 5ª derivada do seno é cos, que nunca passa de 1.
0,5 − 0,0208333 = 0,4791667  ·  sen 0,5 = 0,4794255
O erro de verdade é 0,00026: bate com o limite.
Robozinho perguntaO erro aumenta ou diminui com x mais longe de a?

Aumenta: tem (x − a)ⁿ⁺¹ multiplicando.

Robozinho perguntaE com grau maior?

Pra eˣ, sen e cos, diminui: o (n + 1)! embaixo cresce muito rápido.

Saiba mais: de onde vem o resto

Pra n = 0, a fórmula diz f(x) − f(a) = f′(c)(x − a): é o próprio Teorema do Valor Médio. Lagrange é o TVM "turbinado".

9. Receita

  1. Rolle / TVM: confere contínua em [a, b] e derivável em (a, b). Iguala f′(c) a (f(b) − f(a))/(b − a) e fica com o c de dentro do intervalo.
  2. L'Hôpital: só com 0/0 ou ∞/∞. Deriva em cima e embaixo separados. Confere de novo antes de repetir.
  3. 0·∞: vira fração. Potência indeterminada: ln, calcula, eresultado.
  4. Taylor em a: tabela com f, f′, f″, … em a; cada uma dividida por k! vezes (x − a)ᵏ.
  5. Erro: |f⁽ⁿ⁺¹⁾| ≤ M no intervalo → |erro| ≤ M·|x − a|ⁿ⁺¹/(n + 1)!.
