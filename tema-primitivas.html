1. Derivar ao contrário

Uma primitiva (ou antiderivada) de f é uma função F com F′ = f. Se F é primitiva, F + C também é (a derivada do número C é 0), e pelo Valor Médio são só essas. Escreve-se ∫ f(x) dx = F(x) + C (a "integral indefinida").

quem tem derivada 3x²?
Pensa na tabela de derivadas ao contrário.
(x3)′ = 3x²  →  x3 serve
(x3 + 7)′ = 3x²   (x3 − 2)′ = 3x²
Qualquer número somado também serve.
∫ 3x² dx = x3 + C
O "+ C" representa todas de uma vez.
A família x³ + C: a mesma curva deslocada pra cima e pra baixo. Todas têm a mesma inclinação em cada x.
Robozinho perguntaUma primitiva de 2x?

x² (ou x² + qualquer número).

Robozinho perguntaPor que todas as primitivas diferem só por uma constante?

Se F′ = G′, então (F − G)′ = 0, e pelo Valor Médio F − G é constante.

Saiba mais: o símbolo ∫

É um S alongado, de "soma". O motivo aparece em Integrais: a área sob uma curva é uma soma de retângulos finos, e ela se calcula com primitivas.

2. A regra da potência ao contrário

∫ xn dx = xn + 1n + 1 + C (n ≠ −1): soma 1 no expoente e divide pelo novo expoente. Número multiplicando fica, e soma integra parte por parte. O caso n = −1 é especial: ∫ 1x dx = ln|x| + C.

∫ (6x² − 4x + 5) dx
Parte por parte.
6 · x33 − 4 · x²2 + 5x
x² → x³/3; x → x²/2; o 5 (que é 5x⁰) → 5x.
= 2x3 − 2x² + 5x + C
Simplificando. Um C só no fim basta.
conferindo: (2x3 − 2x² + 5x)′ = 6x² − 4x + 5 ✔
Sempre dá pra conferir derivando.
Robozinho pergunta∫ x⁴ dx?

x⁵/5 + C.

Robozinho perguntaPor que a regra não serve pra n = −1?

Daria x⁰/0: divisão por zero. A primitiva de 1/x é ln|x|.

Saiba mais: por que ln|x| e não ln x

1/x existe pra x negativo também. Pra x < 0, (ln(−x))′ = (1/(−x))·(−1) = 1/x. O módulo junta os dois lados.

3. Reescrever antes de integrar

Igual em Regras de derivação: raiz vira expoente fração, 1/xⁿ vira x⁻ⁿ, e produtos e frações com um termo embaixo se abrem antes. Não existe "regra do produto" simples pra integral.

∫ (√x + 1x²) dx = ∫ (x1/2 + x−2) dx
Reescrevendo.
x3/23/2 + x−1−1 = 23x3/2 − 1x + C
1/2 + 1 = 3/2 e −2 + 1 = −1. Dividir por 3/2 é multiplicar por 2/3.
∫ (x + 2)² dx = ∫ (x² + 4x + 4) dx = x33 + 2x² + 4x + C
Abrindo o quadrado primeiro.
Robozinho pergunta∫ (x² + x)/x dx?

∫ (x + 1) dx = x²/2 + x + C.

Robozinho pergunta∫ x·x² dx é (x²/2)·(x³/3)?

Não! x·x² = x³, e a primitiva é x⁴/4. Primitiva de produto não é produto de primitivas.

Saiba mais: e quando não dá pra abrir?

Produtos como x·eˣ pedem a "integração por partes", que é a regra do produto ao contrário. Fica pra Cálculo 2, junto com outras técnicas.

4. A tabela: exponencial, seno, cosseno e arctg

Lendo a tabela de derivadas de trás pra frente: ∫ ex dx = eˣ + C; ∫ ax dx = aˣ/ln a + C; ∫ cos x dx = sen x + C; ∫ sen x dx = −cos x + C; ∫ 11 + x² dx = arctg x + C.

(−cos x)′ = sen x  →  ∫ sen x dx = −cos x + C
O sinal de menos é o erro mais comum. Confere derivando.
∫ 2x dx = 2xln 2 + C
Porque (2ˣ)′ = ln 2 · 2ˣ: tem que dividir pelo ln 2 pra compensar.
∫ (3 cos x − ex) dx = 3 sen x − ex + C
Parte por parte.
Robozinho pergunta∫ −sen x dx?

cos x + C.

Robozinho pergunta∫ 5eˣ dx?

5eˣ + C.

Saiba mais: nem toda função tem primitiva "escrevível"

ex² tem primitiva (toda função contínua tem), mas ela não se escreve com as funções conhecidas. É a famosa função erro da estatística, calculada numericamente.

5. Achando o C: condição inicial

Se o problema dá um ponto (F(a) = b), ele escolhe uma curva da família: integra com + C, substitui o ponto e resolve pra C. Na física: posição ← velocidade ← aceleração.

F′(x) = 2x + 1   e   F(1) = 5
F(x) = x² + x + C
Integrando.
1 + 1 + C = 5 → C = 3 → F(x) = x² + x + 3
Substituindo x = 1.
Só uma curva da família passa por (1, 5).
v(t) = 3t², s(0) = 2  →  s(t) = t³ + C, C = 2
Posição a partir da velocidade.
Robozinho perguntaF′(x) = cos x e F(0) = 4. Quem é F?

sen x + C, e sen 0 + C = 4: F = sen x + 4.

Robozinho perguntaPor que precisa de uma condição pra achar C?

A derivada "apaga" a constante. Só um valor da função traz ela de volta.

Saiba mais: equações diferenciais

"F′ = f com F(a) = b" é a equação diferencial mais simples que existe. Física, biologia e economia estão cheias de outras mais complicadas, do tipo y′ = k·y (crescimento exponencial).

6. Com ax + b dentro: divide pelo a

A cadeia ao contrário, no caso mais comum: se F′ = f, então ∫ f(ax + b) dx = F(ax + b)/a + C. Derivar F(ax + b) traria um "vezes a"; integrando, ele aparece como "dividido por a".

∫ e4x dx = e4x4 + C
Conferindo: (e4x/4)′ = 4e4x/4 = e4x. ✔
∫ cos(2x + 1) dx = sen(2x + 1)2 + C
∫ (3x − 1)4 dx = (3x − 1)55 · 3 = (3x − 1)515 + C
Potência: soma 1 no expoente, divide pelo novo expoente E pelo a.
Robozinho pergunta∫ sen(5x) dx?

−cos(5x)/5 + C.

Robozinho pergunta∫ e^(−x) dx?

a = −1: −e^(−x) + C.

Saiba mais: só funciona com ax + b

∫ cos(x²) dx NÃO é sen(x²)/(2x). Dividir só funciona quando a derivada de dentro é um número. Com x² dentro, precisa ter um 2x fora (próxima etapa).

7. Substituição (a cadeia ao contrário)

Se aparece uma função e a derivada dela multiplicando, chama a função de u. Aí du = u′ dx e a integral vira uma da tabela em u. No fim, volta pra x.

∫ 2x(x² + 1)³ dx
Dentro: x² + 1. A derivada dele, 2x, está multiplicando.
u = x² + 1,   du = 2x dx
Troca de variável.
∫ u³ du = u44 + C = (x² + 1)44 + C
Integra em u e volta.
∫ x ex² dx:   u = x², du = 2x dx → x dx = du2
Falta um 2: ajusta dividindo.
∫ eu2 du = ex²2 + C
Robozinho perguntaEm ∫ cos x · sen x dx, quem é u?

u = sen x (du = cos x dx): ∫ u du = sen²x/2 + C.

Robozinho perguntaE em ∫ 2x/(x² + 1) dx?

u = x² + 1: ∫ du/u = ln(x² + 1) + C.

Saiba mais: a notação du = u′ dx

Parece mágica dividir e multiplicar dx, mas é só a cadeia: (F(u(x)))′ = F′(u)·u′. A notação de Leibniz deixa isso automático.

8. Conferir sempre (e os erros clássicos)

Integral é difícil de achar, mas fácil de conferir: deriva a resposta e vê se volta pro que estava dentro. Os erros clássicos aparecem todos nessa conferência.

∫ sen x dx = cos x?  →  (cos x)′ = −sen x ✘
Sinal trocado. O certo é −cos x.
∫ e3x dx = e3x?  →  (e3x)′ = 3e3x ✘
Faltou dividir por 3.
∫ 1x² dx = ln(x²)?  →  (ln x²)′ = 2x ✘
1/x² é x⁻², regra da potência: −1/x + C.
∫ (x² + 1)² dx = (x² + 1)³3?  →  derivada: (x² + 1)² · 2x ✘
Faltou o 2x fora pra fazer substituição. Tem que abrir o quadrado.
Robozinho perguntaComo conferir ∫ x³ dx = x⁴/4 + C?

(x⁴/4)′ = x³ ✔.

Robozinho perguntaEsqueci o + C. Está errado?

Numa integral indefinida, sim: a resposta é a família toda. Em integral definida (próximo assunto) o C cancela.

Saiba mais: computador integra?

Sim (álgebra simbólica). Mas conferir derivando é a forma mais rápida de pegar erro na prova, sem calculadora.

9. Receita

  1. Reescreve: raiz → expoente fração, 1/xⁿ → x⁻ⁿ, abre produtos e divide frações com um termo embaixo.
  2. Potência: soma 1 no expoente e divide por ele (1/x → ln|x|).
  3. Tabela: eˣ → eˣ; aˣ → aˣ/ln a; cos → sen; sen → −cos; 1/(1 + x²) → arctg.
  4. ax + b dentro: integra como se fosse x e divide por a.
  5. Função e sua derivada multiplicando: u = a função, du = u′ dx.
  6. + C sempre; com condição, substitui e acha C.
  7. Confere derivando.

O laboratório da família de primitivas

Escolha a função f. Em cinza, várias primitivas F + C; em laranja, a que você escolhe com o controle de C. No desafio, ache o C que faz a primitiva passar pelo ponto vermelho.
