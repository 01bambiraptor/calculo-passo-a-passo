Caminho principal

Em cada etapa: um resumo curto e a animação (ou as perguntas, no modo socrático). As caixinhas "saiba mais" são opcionais e não contam no progresso.

1. A ideia: comparar dois gráficos

Resolver f(x) = g(x) é achar onde os dois gráficos se cruzam. Resolver f(x) > g(x) é achar onde o gráfico de f está acima do de g. Toda a técnica deste assunto é um jeito de responder isso sem precisar desenhar.

x² = x + 2
Onde a parábola y = x² encontra a reta y = x + 2?
Verde: x². Laranja: x + 2. Elas se cruzam em x = −1 e x = 2.
x² > x + 2  →  x < −1  ou  x > 2
Fora do intervalo entre os cruzamentos, a parábola está acima da reta.
x² < x + 2  →  −1 < x < 2
No meio, a reta está por cima.
Robozinho perguntaSe dois gráficos nunca se cruzam, quantas soluções tem f(x) = g(x)?

Nenhuma. E f(x) > g(x) vale pra todo x ou pra nenhum, dependendo de qual está por cima.

Robozinho perguntaOs pontos de cruzamento entram em f(x) ≥ g(x)?

Sim: lá f(x) = g(x), e o "ou igual" aceita.

Saiba mais: por que não desenhar sempre

Desenhar dá a ideia, mas o desenho não tem precisão: onde exatamente cruza? 1,5? 1,48? A conta dá o número exato.

2. Tudo de um lado, comparar com zero

Primeiro passo de sempre: passar tudo pra um lado e deixar zero do outro. Assim a pergunta "f está acima de g?" vira "essa expressão é positiva?". Depois, fatorar: com a expressão em pedaços multiplicados, o sinal fica fácil de descobrir.

x² > x + 2
O exemplo da etapa 1.
x² − x − 2 > 0
Passei o x + 2 pro outro lado.
(x + 1)(x − 2) > 0
Fatorando (raízes −1 e 2, da Bhaskara).
quando um produto é positivo?
É essa pergunta que a etapa 3 responde.
Robozinho perguntaPor que é melhor comparar com zero?

Porque saber se um número é positivo ou negativo é fácil quando ele está fatorado: basta contar os sinais dos pedaços.

Robozinho perguntaPasse 3x + 1 ≤ x − 5 pro formato "algo ≤ 0".

2x + 6 ≤ 0.

Saiba mais: igual à inequação do 2º grau

Na inequação do 2º grau a gente fez isso olhando a parábola. O quadro de sinais faz o mesmo, mas funciona com quantos fatores quiser.

3. O sinal de um produto

Um produto é positivo quando tem uma quantidade par de fatores negativos (0, 2, 4...), e negativo quando tem uma quantidade ímpar. E ele é zero quando algum fator é zero.

(+) · (+) = +    (−) · (−) = +    (+) · (−) = −
A regra dos sinais de sempre.
(−) · (−) · (−) = (+) · (−) = −
Com três negativos: dois se cancelam e sobra um.
x = 0:   (0 + 1)(0 − 2) = (+)(−) = −
Teste no exemplo: em x = 0 o produto é negativo.
x = 3:   (3 + 1)(3 − 2) = (+)(+) = +
Em x = 3, positivo.
o sinal só muda nas raízes
Cada fator troca de sinal só na própria raiz. Então entre duas raízes seguidas, o sinal de tudo fica parado. Por isso basta testar um ponto em cada pedaço.
Robozinho perguntaQual o sinal de (−2) · 5 · (−1) · (−3)?

Três negativos: ímpar, negativo.

Robozinho perguntaEm que pontos (x − 4)(x + 1) vale zero?

Em x = 4 e x = −1.

Saiba mais: o fator mais simples

Um fator ax + b com a > 0 é negativo à esquerda da raiz e positivo à direita. Com a < 0, é o contrário. É só isso que o quadro de sinais usa.

4. O quadro de sinais

Receita: (1) acha a raiz de cada fator; (2) coloca as raízes em ordem; elas dividem a reta em pedaços; (3) pra cada fator, marca + ou − em cada pedaço; (4) multiplica os sinais de cada coluna; (5) lê a resposta.

(x − 1)(x + 2)(3 − x) > 0
Três fatores.
raízes: 1, −2 e 3  →  em ordem: −2, 1, 3
x − 1 zera em 1; x + 2 em −2; 3 − x em 3.
x < −2−2 < x < 11 < x < 3x > 3
x − 1−−++
x + 2−+++
3 − x+++−
produto+−+−
Cada linha é um fator. Repara no 3 − x: ele é positivo à esquerda do 3 (x pequeno) e negativo à direita, porque o x vem com sinal de menos.
> 0:   x < −2  ou  1 < x < 3
As colunas com + na última linha. Como é > (e não ≥), as raízes ficam de fora.
Robozinho perguntaSe fosse ≥ 0, o que mudava?

As raízes entrariam: x ≤ −2 ou 1 ≤ x ≤ 3.

Robozinho perguntaPrecisa de uma linha pra cada fator mesmo?

Ajuda a não errar. Com prática dá pra contar os negativos de cabeça, mas no papel a tabela evita escorregão.

Saiba mais: atalho da alternância

Se todas as raízes são simples, o sinal vai alternando de pedaço em pedaço. Basta descobrir o sinal do último pedaço (x bem grande) e ir trocando pra esquerda. Com raiz dupla, o sinal não troca nela (etapa 7).

5. Quocientes: o de baixo nunca entra

Divisão segue a mesma regra de sinais da multiplicação, então o quadro funciona igual. A diferença: a raiz do denominador nunca entra na resposta (não existe divisão por zero), mesmo com ≤ ou ≥.

x + 1x − 3 ≤ 0
Uma fração comparada com zero.
raízes: −1 (em cima) e 3 (embaixo)
O de cima zera em −1; o de baixo em 3.
x < −1−1 < x < 3x > 3
x + 1−++
x − 3 (embaixo)−−+
fração+−+
O mesmo quadro, sinal por sinal.
−1 ≤ x < 3
O −1 entra (a fração vale 0, e ≤ aceita). O 3 fica de fora: lá a fração nem existe.
Robozinho perguntaResolva xx + 2 > 0.

Raízes 0 (em cima) e −2 (embaixo). Positivo fora: x < −2 ou x > 0.

Robozinho perguntaE se fosse ≥ 0?

x < −2 ou x ≥ 0. O 0 entra; o −2 continua de fora.

Saiba mais: domínio primeiro

Um hábito que evita erro: antes de tudo, anota "x ≠ (raiz do denominador)". Na hora de escrever a resposta, confere se esse número ficou de fora.

6. Não multiplique pelo denominador

Em equação, dá pra multiplicar tudo pelo denominador. Em inequação, não: o denominador pode ser negativo, e aí o sinal teria que virar, mas você não sabe se vira ou não. O caminho seguro: tudo de um lado, junta numa fração só e faz o quadro.

xx − 2 > 1
Vamos ver o erro primeiro.
errado:  x > x − 2  →  0 > −2  (sempre verdade?!)
Multiplicando por x − 2 "sem pensar", parece que todo x serve. Mas x = 0 dá 0/(−2) = 0, que não é maior que 1. Algo deu errado.
xx − 2 − 1 > 0  →  x − (x − 2)x − 2 > 0  →  2x − 2 > 0
O certo: tudo de um lado, mesmo denominador, e simplifica em cima.
2 é positivo, então precisa x − 2 > 0  →  x > 2
Agora sim. Teste: x = 3 dá 3/1 = 3 > 1 ✔; x = 0 dá 0 > 1? não ✔.
Robozinho perguntaQuando eu posso multiplicar uma inequação por um número?

Quando sei o sinal dele. Positivo: o sinal fica. Negativo: vira. Uma expressão com x pode ser os dois, então não dá.

Robozinho perguntaE se o denominador fosse x² + 1?

Aí pode multiplicar: x² + 1 é sempre positivo, o sinal não vira.

Saiba mais: dá pra fazer separando em casos

Outra saída é separar: caso x − 2 > 0 (multiplica sem virar) e caso x − 2 < 0 (multiplica virando), e juntar as respostas. Funciona, mas o quadro é mais rápido.

7. Fatores que não trocam de sinal

Alguns fatores nunca trocam de sinal: um quadrado como (x − 1)² é ≥ 0 (só zera na raiz), e coisas como x² + 1 são sempre positivas. Um número negativo na frente (tipo −3) inverte todos os sinais da última linha.

(x − 1)²(x + 3) < 0
Um fator ao quadrado.
x < −3−3 < x < 1x > 1
(x − 1)²+++
x + 3−++
produto−++
A linha do quadrado é + dos dois lados do 1: ele não troca de sinal ali.
x < −3
Negativo só no primeiro pedaço. E o x = 1? Lá o produto vale 0, que não é < 0: fica de fora.
(x − 1)²(x + 3) ≤ 0  →  x ≤ −3  ou  x = 1
Com ≤, o 1 entra como ponto isolado: o produto vale 0 lá.
−2(x + 3) > 0  →  x + 3 < 0
O −2 é negativo sempre: é só virar o sinal pra se livrar dele (ou pôr uma linha "−2" toda de − no quadro).
Robozinho perguntaQual o sinal de x² + 4 pra x = −10?

Positivo: 100 + 4. Na verdade, pra qualquer x.

Robozinho perguntaResolva (x + 2)² ≥ 0.

Todo x real: um quadrado nunca é negativo.

Saiba mais: a ligação com polinômios

É a mesma coisa de "raiz dupla toca e volta" (Polinômios, etapa 4): o gráfico encosta no eixo e não muda de lado.

8. Problemas com fórmula: direto e inverso

Em problema com fórmula, tem duas perguntas possíveis. Direto: sei o x, calculo o resultado (só substituir). Inverso: sei o resultado, quero o x (precisa resolver uma equação ou inequação). O inverso costuma dar mais trabalho.

P = 5 + 3d
Uma corrida de táxi: R$ 5 de bandeirada mais R$ 3 por km rodado (d).
direto: d = 4  →  P = 5 + 12 = 17
Quanto custa uma corrida de 4 km? R$ 17.
inverso: 5 + 3d = 32  →  3d = 27  →  d = 9
Paguei R$ 32: quantos km andei? 9 km.
5 + 3d ≤ 50  →  d ≤ 15
Tenho R$ 50: até quantos km dá pra ir? Uma inequação.
Robozinho perguntaUma conta de luz é C = 20 + 0,8k (k em kWh). Quanto deu um mês de 100 kWh?

20 + 80 = R$ 100 (problema direto).

Robozinho perguntaE se a conta veio R$ 140, quantos kWh?

0,8k = 120, k = 150 kWh (inverso).

Saiba mais: inverso e função inversa

Resolver o problema inverso pra todo resultado possível é achar a função inversa: d = (P − 5)/3.

9. Receita

  1. Tudo de um lado, zero do outro. Com fração: junta numa fração só (nunca multiplica pelo denominador).
  2. Fatora em cima e embaixo.
  3. Raízes de cada fator, em ordem na reta. Anota quais são do denominador.
  4. Quadro: + ou − de cada fator em cada pedaço; multiplica a coluna.
  5. Lê: > 0 pega os +, < 0 os −. Com ≤ ou ≥, as raízes de cima entram; as de baixo nunca.
  6. Confere testando um número de dentro e um de fora da resposta.

O laboratório do quadro de sinais

Monte uma expressão com até três fatores (x − r). Cada fator pode ir em cima ou embaixo da fração. O quadro de sinais, o gráfico e a resposta aparecem sozinhos. No desafio, monte uma expressão que tenha exatamente a resposta pedida.
