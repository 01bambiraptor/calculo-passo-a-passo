1. A definição com ε e δ

"lim f(x) = L quando x → p" quer dizer: para qualquer margem ε > 0 que alguém exigir em volta de L, existe uma margem δ > 0 em volta de p tal que 0 < |x − p| < δ garante |f(x) − L| < ε. Na prática: você recebe o ε e tem que achar o δ.

f(x) = 2x + 1,   p = 3,   L = 7
Queremos mostrar que 2x + 1 chega perto de 7 quando x chega perto de 3.
|f(x) − 7| = |2x − 6| = 2|x − 3|
Sempre começa pela distância de f até L, e tenta fazer aparecer |x − p|.
2|x − 3| < ε  ⟺  |x − 3| < ε2
Divide os dois lados por 2.
δ = ε2
Com essa margem, toda vez que x está a menos de δ do 3, f está a menos de ε do 7.
Faixa cinza: 7 ± ε (com ε = 0,8). Com δ = 0,4 o pedaço da reta entre 2,6 e 3,4 fica todo dentro da faixa.
Robozinho perguntaSe ε = 0,1, qual δ serve pra 2x + 1 perto de 3?

δ = 0,05 (qualquer valor menor também serve).

Robozinho perguntaE se a função fosse −4x + 2?

|−4x + 2 − L| = 4|x − p|, então δ = ε/4. Numa reta, δ = ε dividido pelo valor absoluto da inclinação.

Saiba mais: e em função que não é reta?

Em x² perto de 2: |x² − 4| = |x − 2|·|x + 2|. Prendendo x perto de 2 (por exemplo |x − 2| < 1, então |x + 2| < 5), dá δ = o menor entre 1 e ε/5. É o item 2c da Lista 1.

2. Limites laterais e funções por partes

O limite em p existe só se os dois laterais existem e são iguais: chegando pela esquerda (x → p⁻) e pela direita (x → p⁺). Em função por partes, cada lado usa a sua fórmula. Se tem uma letra desconhecida, iguala os laterais e resolve.

f(x) = x + c se x < 1  ·  x² + 2 se x ≥ 1
Qual c faz o limite em 1 existir?
limx→1⁻ = 1 + c    limx→1⁺ = 1 + 2 = 3
Pela esquerda vale a primeira fórmula; pela direita, a segunda.
1 + c = 3  →  c = 2
Igualando os dois lados.
Com c = 2 os dois pedaços se encontram em (1, 3).
Robozinho perguntaSe os laterais dão 3 e 5, o limite existe?

Não. Precisa ser o mesmo número dos dois lados.

Robozinho perguntaE |x|/x em 0?

Pela esquerda −1, pela direita 1: não existe.

Saiba mais: o valor no próprio ponto não importa

O limite olha só pra perto de p, nunca pra p. A função pode nem estar definida ali, ou ter um valor "fora do lugar", e o limite continua o mesmo.

3. Teorema do Confronto (sanduíche)

Se g(x) ≤ f(x) ≤ h(x) perto de p, e g e h têm o mesmo limite L, então f também tem limite L: ela fica espremida. Serve muito com seno e cosseno, que ficam sempre entre −1 e 1.

x² sen(1x)   quando x → 0
sen(1/x) não tem limite em 0 (oscila sem parar). Mas está multiplicado por x².
−1 ≤ sen(1x) ≤ 1  →  −x² ≤ x² sen(1x) ≤ x²
Multiplica tudo por x², que é positivo: as desigualdades não viram.
limx→0 (−x²) = 0 = limx→0 x²  →  o limite é 0
As duas paredes vão pra 0, e a função vai junto.
A curva verde oscila, mas sempre entre as parábolas tracejadas.
Robozinho perguntaSe 2x ≤ f(x) ≤ x² + 1 perto de 1, qual o limite de f em 1?

As duas paredes valem 2 em x = 1. Limite 2.

Robozinho perguntaPor que precisa que as duas paredes tenham o mesmo limite?

Se fossem diferentes, a função poderia ficar pulando no meio delas, sem chegar a um número.

Saiba mais: "limitada vezes vai pra zero, vai pra zero"

Esse é o atalho que sai do confronto: se |g| ≤ M e f → 0, então f·g → 0. É o caso de x² · sen(1/x).

4. O limite trigonométrico fundamental

limx→0 sen xx = 1 (x em radianos). A partir dele saem vários outros: arrume a conta pra aparecer sen(□)/□ com o mesmo □ embaixo.

x = 0,5 → 0,9589  ·  x = 0,1 → 0,9983  ·  x = 0,01 → 0,99998
Calculando sen x / x cada vez mais perto de 0.
sen(4x)3x = sen(4x)4x · 43
Pra ter 4x embaixo, multiplica e divide por 4.
→ 1 · 43 = 43
Quando x → 0, o 4x também vai pra 0, e sen(4x)/(4x) → 1.
1 − cos xx² · 1 + cos x1 + cos x = sen2 xx²(1 + cos x)
Com cosseno: multiplica pelo "conjugado". 1 − cos² = sen².
= (sen xx)² · 11 + cos x → 1 · 12 = 12
cos 0 = 1, então embaixo fica 1 + 1.
Robozinho perguntaQuanto dá tg x / x em 0?

tg x/x = (sen x/x)·(1/cos x) → 1·1 = 1.

Robozinho perguntaE sen(x)/x quando x → π?

sen π/π = 0. O limite fundamental é só quando o de dentro vai pra 0.

Saiba mais: de onde vem esse 1

No círculo trigonométrico, para 0 < x < π/2 vale cos x < sen x / x < 1 (comparando áreas de triângulos e do setor). Com x → 0, o cos x vai pra 1, e o confronto (etapa 3) dá o resultado. É a desigualdade da questão 3 da Lista 2.

5. Limites infinitos (assíntota vertical)

Quando o de baixo vai pra 0 e o de cima não, a fração explode: o limite é +∞ ou −∞. O sinal sai do sinal de cima e de baixo perto do ponto. Por isso olha cada lado separado.

1x  em 0:   limx→0⁺ = +∞    limx→0⁻ = −∞
Pela direita, 1 dividido por positivo pequeno. Pela esquerda, por negativo pequeno.
x + 2(x − 1)²  em 1
Em cima: 3 (positivo). Embaixo: ao quadrado, positivo dos dois lados.
limx→1 = +∞
Os dois lados dão +∞, então dá pra escrever direto.
A reta x = 1 é uma assíntota vertical: o gráfico sobe sem parar dos dois lados.
Robozinho perguntaQual o sinal de (x − 5)/x² quando x → 0⁺?

Em cima −5, embaixo positivo pequeno: −∞.

Robozinho pergunta"Limite = ∞" quer dizer que o limite existe?

Não como número. É um jeito de dizer COMO ele não existe: crescendo sem parar.

Saiba mais: 0/0 é outra história

Se em cima também vai pra 0, é o caso 0/0 de Limites: precisa simplificar antes. Só "número diferente de 0 sobre 0" explode direto.

6. Limites no infinito

Quando x → ±∞, quem manda é a maior potência. Truque: divide em cima e embaixo pela maior potência de x do de baixo; os termos tipo número/x vão pra 0. Com raiz, lembre que √(x²) = |x|, que é −x quando x é negativo. Com ∞ − ∞ e raiz, use o conjugado.

3x² + 16x² − x = 3 + 1/x²6 − 1/x → 36 = 12
Dividindo tudo por x². 1/x² e 1/x vão pra 0.
grau de cima < grau de baixo → 0    grau de cima > grau de baixo → ±∞
Os outros dois casos. Igual: a razão dos números da frente.
√4x² + 1x + 1   com x → −∞
Embaixo a maior potência é x. Em cima, √4x² + 1 = |x|·√4 + 1/x².
|x| = −x  →  −x √4 + 1/x²x(1 + 1/x) → −2
x é negativo. Com x → +∞ daria +2: duas assíntotas horizontais diferentes.
√x² + x − x = x√x² + x + x = 1√1 + 1/x + 1 → 12
Conjugado: (a − b)(a + b) = a² − b². Sobra x² + x − x² = x em cima.
Robozinho perguntaQuanto dá (2x³ − x)/(5x³ + 4) no infinito?

2/5.

Robozinho perguntaE x/(x² + 1)?

0: o de baixo cresce mais rápido.

Saiba mais: assíntota horizontal

Se f(x) → L quando x → +∞ (ou −∞), a reta y = L é uma assíntota horizontal: o gráfico vai encostando nela.

7. Continuidade e o Teorema do Valor Intermediário

f é contínua em p se f(p) existe, o limite existe e os dois são iguais. Polinômios, raízes, exp, log, seno e cosseno são contínuos onde estão definidos. TVI: se f é contínua em [a, b] e f(a), f(b) têm sinais opostos, existe raiz entre a e b.

f(x) = x3 + x − 1   em [0, 1]
Polinômio: contínuo em todo lugar.
f(0) = −1 < 0    f(1) = 1 > 0
Sinais opostos nas pontas.
existe c em (0, 1) com f(c) = 0
Pra sair do negativo e chegar no positivo sem pular, a curva tem que cruzar o zero.
A raiz está perto de 0,68. O TVI garante que existe, sem dizer onde.
Robozinho pergunta1/x muda de sinal entre −1 e 1. Tem raiz?

Não: 1/x não é contínua em [−1, 1] (não existe em 0). O TVI precisa de continuidade.

Robozinho perguntaComo achar 3 raízes com o TVI?

Achar 3 intervalos separados com troca de sinal. É o exercício n, mais abaixo.

Saiba mais: o método da bisseção

Partindo [0, 1] ao meio, testa f(0,5): se for negativo, a raiz está em [0,5; 1]. Repetindo, o intervalo encolhe pela metade a cada passo. É assim que calculadoras acham raízes.

8. O limite que define o número e

limx→+∞ (1 + 1/x)ˣ = e ≈ 2,718. Variações: (1 + k/x)ˣ → eᵏ e, com x → 0, (1 + kx)1/x → eᵏ. O jeito de ver: o número somado ao 1 e o expoente têm que ser "inversos"; o que sobrar vai pro expoente do e.

x = 10 → 2,594  ·  x = 100 → 2,705  ·  x = 10000 → 2,7181
(1 + 1/x)ˣ chegando perto de e.
(1 + 3x)x = [(1 + 3x)x/3]3
Pra ter "1 + 1/u com expoente u", u = x/3. O que falta (3) vai pra fora.
→ e3
O de dentro dos colchetes vai pra e.
(1 + 5x)1/x   com x → 0  →  e5
Mesma ideia: 5x vai pra 0 e o expoente 1/x é 5 vezes 1/(5x).
Robozinho perguntaE (1 − 1/x)ˣ no infinito?

k = −1: e⁻¹ = 1/e.

Robozinho perguntaPor que 1 elevado a ∞ não dá 1?

Porque a base não é exatamente 1: é um pouquinho maior, e o expoente enorme amplifica essa diferença. É uma indeterminação, como 0/0.

Saiba mais: juros compostos

Um real a 100% ao ano, com os juros calculados n vezes no ano, vira (1 + 1/n)ⁿ. Calculando a cada instante (n → ∞), vira e ≈ 2,72.

9. Receita

  1. Substitui primeiro. Número: pronto. Número ≠ 0 sobre 0: ±∞ (olha os sinais de cada lado). 0/0: simplifica.
  2. Por partes ou com módulo: calcula os dois laterais; iguala se tiver letra.
  3. Com seno: faz aparecer sen(□)/□ com o mesmo □ embaixo. Com 1 − cos: conjugado.
  4. Oscila e está multiplicado por algo que vai pra 0: confronto.
  5. x → ±∞: divide pela maior potência de baixo. √(x²) = |x| (negativo se x → −∞). ∞ − ∞ com raiz: conjugado.
  6. 1 elevado a ∞: (1 + k/x)ˣ → eᵏ; (1 + kx)1/x → eᵏ.
  7. ε e δ: escreve |f(x) − L| e faz aparecer |x − p|.
  8. Raiz existe? Contínua e troca de sinal: TVI.

O laboratório do ε e δ

Escolha a função e o tamanho do ε (a faixa horizontal em volta de L). Seu trabalho é achar um δ (a faixa vertical em volta de p) que deixe o pedaço do gráfico todo dentro da faixa de ε. Pedaço fora fica vermelho.

Tenta no papel primeiro. Depois abre a resolução, um passo de cada vez, e compara.

Passo 1Onde estou: continuidade

É polinômio: contínuo em todo ℝ. Então dá pra usar o TVI em qualquer intervalo.

Passo 2Onde estou: procurando trocas de sinal
p(−3) = −13   p(−2) = 2   p(0) = 2   p(1) = −1   p(2) = 2
O que não está escrito, mas existe: p(−3) = −27 + 12 + 2. p(1) = 1 − 4 + 2.
Passo 3Onde estou: três intervalos
(−3, −2): − para +  ·  (0, 1): + para −  ·  (1, 2): − para +

Uma raiz em cada intervalo. Como os intervalos não se encostam, são três raízes diferentes (e grau 3 não tem mais que três).
